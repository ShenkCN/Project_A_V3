## 一、 华硕 (ASUS) 电脑故障排查

**【ASUS-001】开机完全无反应，电源指示灯不亮**
- **现象**：插上电源适配器后，指示灯不亮，按开机键无任何动作。
- **排查**：优先执行 EC 静电重置。拔掉电源适配器与所有外接设备（USB、扩展坞、SD卡），长按电源键 40 秒以上释放主板残余静电，静置 15 分钟后仅连接原装电源适配器再尝试开机[reference:0]。若仍无反应，需检查电源适配器输出电压是否正常，或更换适配器测试。

**【ASUS-002】开机黑屏，但电源指示灯亮、风扇转动**
- **现象**：指示灯亮，风扇在转，屏幕无任何画面输出，外接显示器也无信号。
- **排查**：先做 EC 重置（长按电源键 20 秒以上）。若无效，断电后拆开后盖，拔插内存条并用橡皮清洁金手指，单根内存逐一测试。部分机型需断开电池排线后长按电源键 60 秒彻底重置 EC[reference:1]。若外接显示器正常但内置屏幕黑屏，排查屏幕排线是否松动。

**【ASUS-003】电池无法充电，电量卡在 80% 左右**
- **现象**：插着电源，电池图标显示“已接通，未充电”，电量长时间不增加。
- **排查**：华硕 MyASUS 中可能开启了“电池健康充电”模式，将充电上限限制在 60%/80%。进入 MyASUS → 硬件设置 → 电源与电池 → 电池健康充电，切换为“满容量模式”[reference:2]。同时确认使用的是原装电源适配器，非原装适配器可能功率不足导致无法充电[reference:3]。

**【ASUS-004】开机直接进入 BIOS，无法引导系统**
- **现象**：每次开机都停在 BIOS 界面，保存退出后仍然循环进入。
- **排查**：进入 BIOS 的 Boot 菜单，检查启动顺序中 Windows Boot Manager 是否位于第一位。若硬盘未被识别，检查硬盘是否松动或 SSD 是否损坏。若硬盘正常但 Boot Manager 消失，可能是引导分区损坏，需用 PE U 盘修复引导。

**【ASUS-005】Fn 快捷键失效，亮度/音量无法调节**
- **现象**：按 Fn + F1~F12 无反应，屏幕亮度和音量快捷键不工作。
- **排查**：安装华硕 ATK Package（快捷键驱动）以及 MyASUS 系统控制驱动。在设备管理器中检查“人体学输入设备”下是否有华硕相关 HID 设备，若有黄色感叹号则右键卸载后重启，让系统重新安装驱动。

**【ASUS-006】Wi-Fi 频繁断开，需重启网卡才能恢复**
- **现象**：无线网络间歇性掉线，设备管理器中网卡状态正常，重启后恢复。
- **排查**：在设备管理器中找到无线网卡，右键属性 → 电源管理，取消勾选“允许计算机关闭此设备以节约电源”[reference:4]。更新无线网卡驱动到华硕官网对应机型的最新版本。若使用 MediaTek 网卡且问题持续，可尝试在高级设置中关闭 802.11ax 模式。

**【ASUS-007】开机提示 “CMOS Date/Time Not Set”**
- **现象**：每次开机时间都回到出厂默认值，BIOS 中的日期时间无法保持。
- **排查**：主板上的 CR2032 纽扣电池电量耗尽。拆开后盖找到纽扣电池，更换同型号 CR2032 电池后重新设置 BIOS 时间和启动项。

**【ASUS-008】USB 接口不识别设备，U 盘无反应**
- **现象**：插入 U 盘或外接硬盘后系统无任何提示，设备管理器无新设备出现。
- **排查**：更换其他 USB 接口（Type-A 与 Type-C 交叉测试）。在设备管理器中展开“通用串行总线控制器”，卸载所有 USB Root Hub 后重启，让系统重新枚举。若仅特定接口失效，可能是该接口的供电或物理损坏。

**【ASUS-009】键盘部分按键无响应，或输入乱码**
- **现象**：某些按键敲击后无字符输出，或按 A 出 B。
- **排查**：外接 USB 键盘测试，若外接正常则内置键盘排线可能松动或键盘硬件损坏，需拆机重新插拔排线。若外接键盘也出现同样问题，检查输入法或系统键盘布局设置是否被误改。

**【ASUS-010】屏幕闪烁或出现横向/纵向条纹**
- **现象**：屏幕间歇性闪烁，或出现彩色条纹，外接显示器画面正常。
- **排查**：外接显示器验证。若外接正常，故障在笔记本屏幕排线或液晶面板。检查排线是否被转轴挤压，尝试重新插拔排线。若排线正常但条纹仍在，需更换屏幕面板。

**【ASUS-011】电脑严重发热，风扇狂转后自动关机**
- **现象**：高负载下 CPU 温度迅速升高，风扇满速运转，随后自动断电。
- **排查**：拆机清理散热风扇和出风口的积灰，更换 CPU/GPU 导热硅脂。使用 MyASUS 或 HWiNFO 监控温度，确认是否触发过温保护。若清理后仍然过热，检查散热模组（热管、风扇）是否老化失效。

**【ASUS-012】摄像头无法打开，提示“未找到摄像头”**
- **现象**：视频会议软件中摄像头黑屏，设备管理器中没有摄像头设备。
- **排查**：检查键盘上的摄像头物理防窥拨片是否处于关闭状态。按 Fn + F10（或带摄像头图标的 F 键）切换摄像头开关。在 Windows 隐私设置中确认“允许应用访问摄像头”已开启。若设备管理器中有摄像头但带感叹号，卸载后重启让系统重装驱动。

**【ASUS-013】开机提示 “Boot Device Not Found”**
- **现象**：开机后直接报错，无法进入系统，BIOS 中可看到硬盘但启动失败。
- **排查**：进入 BIOS 检查 Boot Option Priorities，确认 Windows Boot Manager 在第一位。若 Boot Manager 不存在，可能是 EFI 分区损坏，需用 Windows 安装 U 盘进入修复模式，执行 `bootrec /rebuildbcd` 和 `bcdboot` 修复引导。

**【ASUS-014】外接显示器通过 HDMI/Type-C 无信号**
- **现象**：连接外接显示器后，显示器提示“无信号”，笔记本屏幕正常。
- **排查**：按 `Win + P` 切换投影模式为“复制”或“扩展”。更换 HDMI/Type-C 线缆测试。若使用 Type-C 转接器，确认转接器支持视频输出协议（DP Alt Mode）。在显卡控制面板中检查外接显示器是否被识别。

**【ASUS-015】开机后风扇噪音异常大，持续高速运转**
- **现象**：开机后风扇立即满速运转，噪音明显，即使 CPU 温度不高。
- **排查**：进入 MyASUS 检查风扇模式是否被设为“高性能”或“增压”。在 BIOS 中恢复风扇控制为默认设置。若风扇轴承磨损导致异响（咔哒声），需更换风扇模组。

**【ASUS-016】系统蓝屏，错误代码 IRQL_NOT_LESS_OR_EQUAL**
- **现象**：不定时蓝屏，错误代码指向内存或驱动冲突。
- **排查**：运行 Windows 内存诊断（`mdsched.exe`）。若内存测试通过，排查近期安装的驱动或软件，在安全模式下卸载可疑驱动。使用 `sfc /scannow` 和 `DISM /Online /Cleanup-Image /RestoreHealth` 修复系统文件。

**【ASUS-017】触摸板失灵，光标无法移动**
- **现象**：触摸板完全无响应，外接鼠标正常。
- **排查**：按 Fn + F9（或对应触摸板锁定键）确认是否被误禁用。在设备管理器中检查“人体学输入设备”下的触摸板设备，卸载后重启重装驱动。在 Windows 设置 → 触摸板中确认触摸板未被关闭。

**【ASUS-018】充电指示灯闪烁，但无法开机**
- **现象**：电源指示灯闪烁（尤其是橘色/红色），按开机键无反应。
- **排查**：断开电源适配器，长按电源键 40 秒释放静电。重新连接电源适配器后再尝试开机。若指示灯仍闪烁且无法开机，可能是主板供电电路或电池故障，需送修检测。

**【ASUS-019】开机后屏幕亮度极低，几乎看不清内容**
- **现象**：系统启动后屏幕有画面但亮度极低，调亮度快捷键无效。
- **排查**：在显卡控制面板中调整亮度。检查是否安装了第三方亮度调节软件产生冲突。若硬件亮度调节完全失效，可能是屏幕背光升压电路故障，需检修主板。

**【ASUS-020】蓝牙设备无法连接或频繁断连**
- **现象**：蓝牙耳机/鼠标在系统中可见但连接失败，或连接后频繁断开。
- **排查**：在设备管理器中卸载蓝牙适配器，重启后重新安装华硕官网蓝牙驱动。确认蓝牙服务（Bluetooth Support Service）处于运行状态。若使用 2.4GHz Wi-Fi，可能与蓝牙产生频段干扰，尝试切换 Wi-Fi 到 5GHz 频段。


## 二、 ROG 电脑故障排查

**【ROG-001】幻16 关机后屏幕黑屏但风扇持续转动，无法断电**
- **现象**：点击关机后屏幕熄灭，但风扇继续高速运转，按电源键无反应，拔掉适配器也无效。
- **排查**：长按电源键 30 秒强制断电。此问题常见于奥创中心（Armoury Crate）与系统电源管理冲突。进入奥创中心更新到最新版本，或在 BIOS 中更新 EC 固件。部分案例通过卸载并重装无线网卡驱动解决[reference:5]。

**【ROG-002】幻16 游戏中自动关机，可立即重新开机**
- **现象**：运行大型游戏时突然断电关机，但马上又能正常开机，烤机工具也会触发同样问题。
- **排查**：检查电源适配器功率是否足够（ROG 幻16 需 240W 适配器），非原装低功率适配器在高负载下供电不足会导致掉电。使用 HWiNFO 监控 CPU/GPU 温度，确认是否触发过温保护。检查电池健康度，老化电池在高功耗瞬间无法提供峰值电流。

**【ROG-003】幻16 风扇异响，高负载下出现摩擦声/咔哒声**
- **现象**：风扇高速运转时出现周期性异响，低速时也可能有轻微噪音。
- **排查**：拆机检查风扇叶片是否有灰尘堆积或异物卡入。ROG 幻系列底壳有隐藏螺丝（橡胶脚垫下方），拆卸时需先抠开脚垫，避免硬撬断卡扣[reference:7]。若清理后异响仍在，风扇轴承磨损，需更换风扇模组。

**【ROG-004】幻16 频繁蓝屏，重装系统后依然出现**
- **现象**：不定时蓝屏，错误代码多样（如 VIDEO_TDR_FAILURE、DPC_WATCHDOG_VIOLATION）。
- **排查**：重点排查显卡驱动。使用 DDU（Display Driver Uninstaller）在安全模式下彻底清理 Intel 核显和 NVIDIA 独显驱动，然后重装华硕官网认证版本[reference:8]。更新芯片组驱动和雷电控制驱动。若仍蓝屏，检查是否加装非原装内存或 SSD 导致兼容性问题。

**【ROG-005】幻16 网卡频繁断连，Wi-Fi 消失仅剩飞行模式**
- **现象**：右下角网络图标变为飞行模式，Wi-Fi 列表完全消失，重启后暂时恢复。
- **排查**：在设备管理器中卸载无线网卡和蓝牙驱动，拔掉所有外接设备（包括电源、键鼠），重启后重新安装 ROG 官网对应机型的无线网卡驱动[reference:9]。在网卡属性 → 电源管理中取消“允许计算机关闭此设备以节约电源”。

**【ROG-006】ROG 游戏本 CPU 温度过高（90°C+），游戏帧数下降**
- **现象**：游戏过程中 CPU 温度持续 90°C 以上，帧数明显下降，风扇满速。
- **排查**：使用瓶盖或散热支架垫起 D 面，增加进风量。在奥创中心中将 CPU 功耗限制（如锁到 45W），可在帧数仅下降 5% 的情况下显著降低温度[reference:10]。若长期未清灰，拆机清理风扇和散热鳍片，更换高性能导热硅脂。

**【ROG-007】奥创中心（Armoury Crate）无法打开或功能失效**
- **现象**：双击奥创中心图标无反应，或打开后灯光控制、性能模式切换等功能不可用。
- **排查**：在 Windows 设置 → 应用中卸载 Armoury Crate 和 ROG Live Service，重启后从华硕官网重新下载安装。确保 .NET Framework 和 Visual C++ 运行库完整。部分版本需在 BIOS 中开启 Armoury Crate 相关选项。

**【ROG-008】ROG 笔记本键盘灯效失灵，Aura Sync 无法控制**
- **现象**：键盘背光不亮，或颜色/模式无法通过奥创中心更改。
- **排查**：在奥创中心中检查 Aura Sync 是否被关闭。卸载 Armoury Crate 后重新安装，安装过程中确保 Aura 组件被勾选。若仅个别按键不亮，可能是键盘 LED 排线松动或键盘硬件故障。

**【ROG-009】幻16 使用 Type-C 充电时功率不足，电池掉电**
- **现象**：使用 65W/100W PD 充电器时，系统提示“电源功率不足”，高负载下电池电量反而下降。
- **排查**：ROG 幻16 在高性能模式下需 240W 原装适配器才能满血运行。PD 充电仅在轻负载/关机状态下有效，高负载时必须使用原装大功率适配器。检查 Type-C 线缆是否支持 100W（20V/5A）PD 协议。

**【ROG-010】ROG 笔记本屏幕出现坏点/亮点**
- **现象**：屏幕在纯色背景下可见持续发光的白点（亮点）或不发光的黑点（坏点）。
- **排查**：使用在线屏幕测试工具切换纯色背景确认坏点位置和数量。根据 ROG 保修政策，亮点/坏点数量超过标准可申请保修换屏。软件层面无法修复坏点，勿尝试按压屏幕。

**【ROG-011】幻16 睡眠唤醒后黑屏，需强制重启**
- **现象**：合盖睡眠后打开盖子，屏幕不亮，键盘背光可能亮，按任何键无反应。
- **排查**：更新 BIOS 到最新版本（华硕官网下载对应机型 BIOS，通过 EZ Flash 刷写）。在设备管理器中取消网卡和显卡的“允许计算机关闭此设备以节约电源”。在电源选项中禁用“快速启动”和“混合睡眠”。

**【ROG-012】ROG 笔记本扬声器破音/杂音**
- **现象**：播放音频时扬声器出现破音、电流声或只有一边有声。
- **排查**：在奥创中心中检查音效模式设置。卸载 Realtek 音频驱动后重装 ROG 官网版本。若插耳机正常但外放异常，可能是扬声器排线松动或扬声器单元损坏。

**【ROG-013】幻16 外接显示器通过 HDMI 只能输出 4K 30Hz**
- **现象**：外接 4K 显示器时，HDMI 输出被限制在 30Hz，无法达到 60Hz。
- **排查**：确认 HDMI 线缆是否为 HDMI 2.0 或 2.1 标准（18Gbps 以上带宽）。部分 ROG 机型的 HDMI 口直连独显，需在 NVIDIA 控制面板中确认输出模式。使用 Type-C/DP 接口测试是否可达到更高刷新率。

**【ROG-014】ROG 笔记本开机卡在 ROG Logo，无法进入系统**
- **现象**：开机后一直显示 ROG Logo，转圈后卡住或自动重启。
- **排查**：强制断电后重新开机，连续 3 次触发自动修复模式。进入安全模式，卸载最近安装的驱动或软件。若安全模式也无法进入，使用 Windows 安装 U 盘启动修复，或通过华硕恢复分区重装系统。检查 SSD 健康状态（CrystalDiskInfo）。

**【ROG-015】幻16 触摸板在游戏中误触，导致光标乱跳**
- **现象**：使用外接鼠标玩游戏时，手掌误触触摸板导致视角/光标乱跳。
- **排查**：按 Fn + F10（或对应触摸板锁定键）在游戏时禁用触摸板。在 Windows 设置 → 触摸板中开启“连接鼠标时让触摸板保持打开状态”选项，这样外接鼠标时触摸板仍可用，但可配合锁定键临时关闭。

**【ROG-016】ROG 笔记本电池鼓包，触摸板被顶起**
- **现象**：触摸板区域隆起，底壳缝隙变大，电池续航明显下降。
- **排查**：立即停止使用并断开电源适配器。电池鼓包存在安全风险，切勿按压或刺破。联系华硕售后更换电池，鼓包电池不可继续充电或使用。

**【ROG-017】幻16 麦克风无输入，语音通话对方听不到声音**
- **现象**：系统麦克风音量条无波动，录音测试无声音。
- **排查**：在 Windows 隐私设置中确认“允许应用访问麦克风”已开启。在声音设置中检查输入设备是否选择为正确的阵列麦克风。按 Fn + 麦克风静音键（如有）取消静音。在设备管理器中卸载音频输入设备后重启重装驱动。

**【ROG-018】ROG 笔记本 USB-C 接口无法输出视频**
- **现象**：Type-C 转 HDMI/DP 转接器连接显示器无信号，但该接口充电和数据传输正常。
- **排查**：确认转接器支持 DP Alt Mode（视频输出协议）。部分 ROG 机型的 Type-C 口仅支持数据/充电，视频输出需使用 HDMI 或支持全功能 Type-C 的接口。在 BIOS 中检查 Type-C 相关设置是否被禁用。

**【ROG-019】幻16 开机后系统时间不对，每次需手动同步**
- **现象**：开机后时间偏差较大，自动同步时间失败。
- **排查**：更换主板 CR2032 纽扣电池。在 Windows 设置 → 时间和语言 → 日期和时间中，手动同步 `time.windows.com`。若同步失败，检查系统时间服务（Windows Time）是否启动。

**【ROG-020】ROG 笔记本运行中突然黑屏但声音继续**
- **现象**：游戏或视频播放中屏幕突然黑屏，但音频仍在输出，键盘背光正常。
- **排查**：按 `Win + Ctrl + Shift + B` 重启显卡驱动。检查显卡驱动是否为最新版本，使用 DDU 清理后重装。若频繁发生，可能是 GPU 过热或供电不稳，监控 GPU 温度并检查电源适配器。


## 三、 联想电脑故障排查

**【LENOVO-001】开机三短一长报警，无法显示**
- **现象**：按下电源键后，主机发出“嘀—嘀—嘀—长嘀”的报警声，屏幕无显示。
- **排查**：三短一长是典型的内存故障报警。断电后打开机箱/后盖，拔出内存条，用橡皮擦清洁金手指，清理内存插槽灰尘后重新插紧。若有多根内存，逐一单根测试[reference:11]。

**【LENOVO-002】开机连续短促“嘀嘀”声，无法启动**
- **现象**：电源灯亮，风扇转，但主机持续发出快速短促的滴滴声。
- **排查**：ThinkPad 机型连续短促蜂鸣通常指向内存未插好或损坏。断电后重新插拔内存，确保卡扣完全扣合。若仍报警，更换已知良好的内存条测试。部分机型需检查键盘是否卡键（会导致特定蜂鸣码）[reference:12]。

**【LENOVO-003】开机无显示，无报警声，电源灯亮**
- **现象**：按开机键后指示灯亮，风扇转，但屏幕黑屏且无任何蜂鸣声。
- **排查**：先做静电释放：拔掉电源和电池（若可拆卸），长按电源键 30 秒。重新连接电源后尝试开机。若无效，外接显示器测试，若外接正常则内置屏幕排线或面板故障；若外接也无信号，排查内存和主板。

**【LENOVO-004】ThinkPad 开机提示 “Fan Error”**
- **现象**：开机自检时报 Fan Error，随后自动关机。
- **排查**：风扇积灰卡死或风扇轴承损坏。拆机清理风扇叶片和散热鳍片。若清理后风扇仍不转或转速异常，更换风扇模组。临时应急可在 BIOS 中关闭 Fan Error 检测（不推荐长期使用）。

**【LENOVO-005】笔记本电池无法充电，显示“未检测到电池”**
- **现象**：任务栏电池图标显示“未检测到电池”，插电源可开机但电池不充电。
- **排查**：关机后重新插拔电池（若为可拆卸电池）。检查电池接口是否有氧化或松动。在设备管理器中卸载“Microsoft ACPI 兼容的控制方法电池”，重启后让系统重新识别。若仍无法识别，电池或主板充电电路故障。

**【LENOVO-006】开机提示 “Bootmgr is missing”**
- **现象**：开机后屏幕显示 “Bootmgr is missing, Press Ctrl+Alt+Del to restart”。
- **排查**：进入 BIOS 检查硬盘是否被识别且启动顺序正确。若硬盘正常，引导文件可能损坏。使用 Windows 安装 U 盘启动，进入修复模式，在命令提示符中依次执行 `bootrec /fixmbr`、`bootrec /fixboot`、`bootrec /rebuildbcd`。

**【LENOVO-007】Wi-Fi 开关被禁用，无线网络不可用**
- **现象**：网络列表中无任何 Wi-Fi 信号，或显示“Wi-Fi 已关闭”。
- **排查**：检查机身侧面或键盘上的物理无线开关（部分老款 ThinkPad 有硬件拨动开关）。按 Fn + F5（或对应无线快捷键）开启无线。在设备管理器中确认无线网卡未被禁用。

**【LENOVO-008】触摸板失灵，光标不动**
- **现象**：触摸板完全无响应，外接鼠标正常。
- **排查**：双击触摸板左上角（部分联想机型有触摸板开关指示灯）或按 Fn + F6/F8 切换触摸板状态。在设备管理器中卸载触摸板设备后重启。在联想电脑管家中检查触摸板驱动更新。

**【LENOVO-009】联想笔记本开机风扇噪音极大，持续高速**
- **现象**：开机后风扇立即全速运转，噪音明显，系统温度正常。
- **排查**：在 BIOS 中恢复风扇控制默认值。检查联想电脑管家中的散热模式是否设为“高性能”/“野兽模式”。若风扇轴承磨损导致异响，更换风扇。

**【LENOVO-010】系统蓝屏，错误代码 WHEA_UNCORRECTABLE_ERROR**
- **现象**：不定时蓝屏，错误代码指向硬件错误。
- **排查**：WHEA 错误通常与 CPU、内存或主板供电相关。运行内存诊断和硬盘健康检测。检查 CPU 是否过热（散热不良可能导致 WHEA 报错）。更新 BIOS 和芯片组驱动。若频繁出现，需送修检测硬件。

**【LENOVO-011】USB 接口供电不足，外接硬盘频繁掉盘**
- **现象**：外接移动硬盘使用中突然断开，重新插拔后恢复，但反复出现。
- **排查**：使用带外部供电的 USB Hub 或 Y 型 USB 线为硬盘提供额外电力。在设备管理器中取消 USB Root Hub 的“允许计算机关闭此设备以节约电源”。前置 USB 口供电通常弱于后置，优先使用后置接口。

**【LENOVO-012】开机卡在联想 Logo，无法进入系统**
- **现象**：开机后联想 Logo 一直显示，进度圈转完后卡住或自动重启。
- **排查**：强制关机后开机，连续 3 次触发 Windows 自动修复。进入安全模式排查近期更新或驱动。若安全模式正常，可能是显卡/网卡驱动冲突。若安全模式也卡死，使用恢复 U 盘修复或重装系统。

**【LENOVO-013】键盘部分按键失灵，或按键错乱**
- **现象**：某些按键无响应，或按一个键输出多个字符。
- **排查**：外接 USB 键盘测试。若外接正常，内置键盘排线可能松动或键盘膜下有异物/液体残留。清理键盘或更换键盘模组。若外接键盘也有同样问题，排查系统输入法或键盘布局设置。

**【LENOVO-014】屏幕亮度无法调节，快捷键无效**
- **现象**：按 Fn + 亮度键无反应，屏幕始终处于某一亮度。
- **排查**：在显卡控制面板中调整亮度。卸载并重装显卡驱动（尤其是 Intel 核显驱动，负责笔记本屏幕亮度控制）。检查设备管理器中“监视器”下是否为“通用即插即用监视器”，若为“默认监视器”则重装显卡驱动。

**【LENOVO-015】联想笔记本关机后自动重启**
- **现象**：点击关机后系统重新启动，无法彻底关机。
- **排查**：在设备管理器中取消网卡和 USB 设备的“允许计算机关闭此设备以节约电源”。在电源选项中禁用“快速启动”。检查是否有计划任务或第三方软件触发唤醒/重启。更新 BIOS。

**【LENOVO-016】ThinkPad 小红点（TrackPoint）失灵**
- **现象**：小红点无法控制光标，触摸板正常。
- **排查**：在设备管理器中检查 TrackPoint 驱动是否正常。卸载后重启，让系统重新安装。若仅小红点失灵而触摸板正常，可能是小红点模块硬件故障或排线松动。

**【LENOVO-017】开机提示 “0191: System Security - Invalid Remote Change”**
- **现象**：开机自检时报 0191 错误，需进入 BIOS 重新保存设置。
- **排查**：进入 BIOS（F1），按 F9 恢复默认设置，再按 F10 保存退出。若反复出现，检查 CMOS 电池是否电量不足。部分机型需在 BIOS 中重新配置安全启动（Secure Boot）设置[reference:13]。

**【LENOVO-018】笔记本扬声器无声，插耳机正常**
- **现象**：外放无声音，但耳机输出正常。
- **排查**：检查扬声器是否被静音。卸载 Realtek 音频驱动后重装联想官网版本。在 Realtek 音频管理器中确认输出设备设置为“扬声器”而非“耳机”。若驱动正常但外放仍无声，扬声器排线或单元可能损坏。

**【LENOVO-019】摄像头画面倒置或镜像**
- **现象**：视频通话中摄像头画面上下颠倒或左右镜像。
- **排查**：在相机应用或视频软件中查找旋转/镜像设置。部分联想机型需在 Lenovo Vantage 中调整摄像头方向。若系统重装后出现，安装联想官网摄像头驱动。

**【LENOVO-020】联想笔记本充电指示灯闪烁，无法开机**
- **现象**：电源指示灯闪烁（橙色/白色交替），按开机键无反应。
- **排查**：拔掉电源适配器，长按电源键 30 秒释放静电。仅连接电源适配器尝试开机。若指示灯仍闪烁且无法开机，可能是主板供电或电池故障，联系售后检测。


## 四、 华为手机故障排查

**【HUAWEI-001】手机黑屏无法开机，充电无反应**
- **现象**：按电源键无反应，插充电器后屏幕无充电图标，机身无温升。
- **排查**：使用原装充电器持续充电 30 分钟以上再尝试开机。若仍无反应，长按电源键 15 秒以上强制重启[reference:14]。检查充电接口是否有棉絮/氧化物堵塞，用干燥软毛刷轻扫后重试。若充电器插入后无任何温升，排查充电器、数据线或接口硬件故障[reference:15]。

**【HUAWEI-002】手机卡死在开机 Logo，无法进入系统**
- **现象**：开机后一直显示华为 Logo，无法进入桌面，强制重启后依旧。
- **排查**：长按电源键 15 秒强制关机，然后同时按住电源键 + 音量上键进入 Recovery 模式，选择“清除缓存分区”后重启。若仍卡 Logo，可选择“恢复出厂设置”（会清除数据）。若 Recovery 也无法进入，需通过 HiSuite 或 eRecovery 修复系统。

**【HUAWEI-003】手机触屏局部失灵或乱跳**
- **现象**：屏幕某区域无响应，或手指未触碰时屏幕自动乱点。
- **排查**：撕掉非原装钢化膜/保护膜，非原装膜可能干扰触控信号。清洁屏幕表面油污和汗水。在拨号界面输入 `*#*#64663#*#*` 进入硬件检测，测试触摸屏各项功能。若硬件检测仍异常，触摸屏排线或面板故障，需送修。

**【HUAWEI-004】手机耗电异常快，待机也掉电严重**
- **现象**：充满电后待机几小时电量明显下降，发热增加。
- **排查**：进入设置 → 电池 → 耗电排行，查看异常耗电应用。在应用启动管理中限制后台高耗电应用。关闭不必要的定位、蓝牙、热点。若待机耗电依然异常，可能是电池老化（最大容量低于 80%）或主板漏电。

**【HUAWEI-005】手机无法连接 Wi-Fi，或频繁断连**
- **现象**：Wi-Fi 列表中能看到网络但连接失败，或连接后频繁掉线。
- **排查**：忘记网络后重新输入密码连接。重启路由器和手机。在 Wi-Fi 高级设置中将“WLAN 频段”设为 2.4GHz 测试兼容性。若仅特定路由器出现问题，检查路由器是否开启了 MAC 地址过滤或 IP 冲突。

**【HUAWEI-006】手机提示“充电口温度过高，已停止充电”**
- **现象**：充电时弹出温度过高警告，充电暂停，机身发热明显。
- **排查**：拔掉充电器，将手机置于阴凉通风处降温。避免边充电边运行大型游戏或视频。检查充电口是否有异物导致接触电阻增大。使用原装充电器和数据线，非原装充电器可能效率低、发热大。

**【HUAWEI-007】手机扬声器无声，但耳机/蓝牙正常**
- **现象**：外放音乐/通话无声音，插耳机或连蓝牙耳机正常。
- **排查**：检查扬声器孔是否被灰尘/异物堵塞，用软毛刷清理。播放音频时按音量加键确认媒体音量未静音。在硬件检测中测试扬声器。若清理后仍无声，扬声器单元或排线故障。

**【HUAWEI-008】手机无法快充，只显示普通充电**
- **现象**：使用原装快充充电器和线缆，但充电速度慢，不显示“超级快充”。
- **排查**：检查充电线和充电器是否支持华为快充协议（SCP/FCP），非原装配件可能只支持 5V/2A。清洁充电口和线缆接口的灰尘/氧化物。更换另一套原装快充套装测试，以判断是充电器/线缆故障还是手机充电 IC 故障。

**【HUAWEI-009】手机自动重启，频繁出现**
- **现象**：使用中或待机时手机突然自动重启，无固定规律。
- **排查**：检查近期是否安装了不兼容的应用，在安全模式下观察是否仍重启（安全模式仅运行系统应用）。若安全模式正常，逐个卸载第三方应用排查。若安全模式也重启，可能是电池老化（电压不稳）或主板故障。

**【HUAWEI-010】手机存储空间不足，但清理后很快又满**
- **现象**：提示存储空间不足，清理缓存和照片后，短时间内再次出现同样提示。
- **排查**：在设置 → 存储中查看各分类占用。重点检查微信/QQ 聊天记录和缓存、应用数据、系统日志。部分应用（如社交媒体）会持续生成缓存，需在应用内清理。若系统数据占用异常大，可考虑备份后恢复出厂设置。

**【HUAWEI-011】手机蓝牙无法连接车载系统**
- **现象**：手机蓝牙搜不到车载蓝牙，或配对失败。
- **排查**：在车载系统中删除已配对的旧手机记录，在手机中删除车载蓝牙记录，双方重新配对。确认车载系统蓝牙处于可发现模式。部分车型需在停车挂 P 挡状态下才能配对。

**【HUAWEI-012】手机屏幕出现绿线/粉线**
- **现象**：屏幕出现纵向或横向的绿色、粉色线条，重启后不消失。
- **排查**：截图后在另一台设备上查看截图——若截图中没有线条，故障在屏幕硬件（排线/面板）；若截图中有线条，故障在 GPU/系统。硬件线条通常需更换屏幕总成，无法通过软件修复。

**【HUAWEI-013】手机相机无法打开，提示“相机故障”**
- **现象**：打开相机应用黑屏或闪退，提示“无法连接到相机”。
- **排查**：重启手机。在设置 → 应用 → 相机中清除缓存和数据。若仍无法打开，在硬件检测中测试摄像头。其他应用（如微信扫码）能否调用摄像头？若所有应用都无法调用，摄像头模组或排线故障。

**【HUAWEI-014】手机指纹识别失灵，无法解锁**
- **现象**：指纹解锁无反应，或识别率极低。
- **排查**：清洁指纹识别区域和手指。删除已录入的指纹，重新录入（录入时保持手指干燥、覆盖不同角度）。若重新录入时系统提示“指纹传感器不可用”，传感器硬件故障。

**【HUAWEI-015】手机通话时对方听不到声音**
- **现象**：通话中对方反馈无声音，但自己可以听到对方。
- **排查**：检查麦克风孔是否被保护壳或灰尘堵塞。在录音机中录音测试，回放确认麦克风是否正常。若录音正常但通话异常，排查通话应用权限或网络问题。若录音也异常，麦克风硬件故障。

**【HUAWEI-016】手机升级系统后卡顿、耗电**
- **现象**：系统更新后手机变卡，应用启动慢，电量消耗加快。
- **排查**：系统大版本更新后，后台会进行应用适配和数据重建，通常 2-3 天后恢复正常。若超过一周仍异常，备份数据后恢复出厂设置。检查新系统版本是否有后续小版本补丁推送。

**【HUAWEI-017】手机无法识别 SIM 卡**
- **现象**：状态栏显示“无 SIM 卡”或“SIM 卡错误”。
- **排查**：关机后取出 SIM 卡托，用橡皮清洁 SIM 卡金属触点，重新插入确保卡托完全到位。将该 SIM 卡插入其他手机测试，确认卡本身是否正常。若其他手机也不识别，联系运营商换卡；若其他手机正常，手机卡槽或读卡电路故障。

**【HUAWEI-018】手机屏幕触摸漂移，充电时尤其严重**
- **现象**：充电时触摸屏乱跳、漂移，不充电时正常。
- **排查**：使用非原装充电器时，充电纹波可能干扰触控信号。更换原装充电器和数据线测试。检查插座地线是否正常（无地线可能导致漏电干扰）。若仅特定充电器出现，避免使用该充电器。

**【HUAWEI-019】手机 NFC 功能无法使用**
- **现象**：NFC 开关打开后，刷卡/支付无反应。
- **排查**：确认 NFC 感应区域（通常在摄像头附近）对准刷卡器。取下金属材质手机壳（金属会屏蔽 NFC 信号）。在设置中检查默认支付应用是否设置正确。若仍无反应，NFC 天线或模块故障。

**【HUAWEI-020】手机提示“系统空间不足，部分功能不可用”**
- **现象**：系统频繁提示系统空间不足，无法拍照或更新应用。
- **排查**：系统空间与用户存储空间不同，系统空间用于存放系统更新包和临时文件。在设置 → 存储中查看“系统”占用。删除不用的系统更新包，清理系统缓存。若系统占用持续增大，可备份后通过 eRecovery 进行系统修复或恢复出厂设置。


## 五、 vivo 手机故障排查

**【VIVO-001】手机黑屏死机，无法响应任何操作**
- **现象**：屏幕黑屏，按电源键和触摸均无反应，手机可能伴有发热。
- **排查**：强制重启：同时按住“电源键”和“音量下键”10 秒以上，直到出现 vivo Logo 后松手[reference:16]。强制重启不会清除手机数据。若强制重启无效，连接原装充电器充电 15 分钟后再次尝试。

**【VIVO-002】手机关机过程中黑屏卡住，无法完成关机**
- **现象**：点击关机后屏幕黑掉，但手机未完全断电，按键无响应。
- **排查**：长按电源键 10 秒以上，或同时按住电源键 + 音量减键 7-10 秒，触发硬件级强制重启[reference:17]。此操作仅清除临时运行文件，不删除个人数据。

**【VIVO-003】手机触屏不灵敏，点击无反应**
- **现象**：屏幕部分区域触摸响应迟钝，或需要用力按压才有反应。
- **排查**：撕掉非原装钢化膜/保护膜。清洁屏幕和手指。在拨号界面输入 `*#*#7777#*#*` 进入工程测试模式，测试触摸屏。若工程测试中触摸正常，可能是系统或应用问题；若仍异常，触摸屏硬件故障。

**【VIVO-004】手机耗电快，待机时也明显掉电**
- **现象**：充满电后夜间待机掉电超过 10%，日常使用续航明显缩短。
- **排查**：进入设置 → 电池 → 耗电排行，查看后台高耗电应用并限制其后台活动。检查是否开启了热点、蓝牙、定位等常驻功能。在设置 → 电池 → 电池健康中查看最大容量，若低于 80% 需考虑更换电池。

**【VIVO-005】手机无法连接 Wi-Fi**
- **现象**：Wi-Fi 开关可打开，但搜索不到网络或连接失败。
- **排查**：忘记网络后重新连接。重启路由器和手机。检查路由器是否开启了 MAC 地址过滤。若其他设备可正常连接同一 Wi-Fi，在手机设置 → 系统管理 → 备份与重置 → 还原网络设置（会清除已保存的 Wi-Fi 密码）。

**【VIVO-006】手机扬声器破音/无声**
- **现象**：外放声音出现破音、杂音，或完全无声，耳机输出正常。
- **排查**：清理扬声器孔灰尘。播放音频时按音量加键确认媒体音量未静音。在工程测试模式中测试扬声器。若仍异常，扬声器单元或排线故障。

**【VIVO-007】手机充电慢或无法充电**
- **现象**：插上充电器后充电速度很慢，或电池图标无充电显示。
- **排查**：使用原装充电器和数据线。清洁充电接口。更换另一套充电器测试，以判断是配件问题还是手机问题。若更换后仍无法充电，充电接口或充电 IC 故障。

**【VIVO-008】手机自动重启**
- **现象**：使用中或待机时频繁自动重启。
- **排查**：检查近期安装的应用，在安全模式下观察是否仍重启。若安全模式正常，卸载可疑应用。若安全模式也重启，备份数据后恢复出厂设置。若恢复出厂后仍重启，可能是电池老化或主板故障。

**【VIVO-009】手机拍照模糊，对焦失败**
- **现象**：相机取景画面模糊，点击对焦无反应，或对焦后仍模糊。
- **排查**：清洁摄像头镜头（指纹油污会导致模糊）。重启相机应用。在工程测试模式中测试对焦功能。若对焦马达损坏，需更换摄像头模组。

**【VIVO-010】手机指纹解锁失灵**
- **现象**：屏下指纹或后置指纹识别率极低，无法解锁。
- **排查**：清洁指纹区域和手指。删除旧指纹，重新录入（录入时覆盖手指不同角度）。若重新录入时提示“指纹传感器异常”，传感器硬件故障。

**【VIVO-011】手机蓝牙连接不稳定**
- **现象**：蓝牙耳机/音箱连接后频繁断连，或声音卡顿。
- **排查**：删除配对记录后重新配对。远离 2.4GHz Wi-Fi 路由器（蓝牙与 2.4GHz Wi-Fi 存在频段干扰）。在蓝牙设置中关闭“蓝牙绝对音量”测试。若仅特定设备异常，该设备蓝牙模块可能存在兼容性问题。

**【VIVO-012】手机屏幕出现竖线/横线**
- **现象**：屏幕显示纵向或横向的彩色线条，重启不消失。
- **排查**：截图后查看——截图中有线条则故障在系统/GPU；截图无线条则故障在屏幕硬件（排线或面板）。屏幕硬件线条通常需更换屏幕总成。

**【VIVO-013】手机通话无声音**
- **现象**：通话时听不到对方声音，或对方听不到自己。
- **排查**：确认通话音量未调至最低。检查听筒/麦克风孔是否被遮挡。在录音机中录音测试麦克风。若录音正常但通话异常，排查通话应用或网络；若录音异常，麦克风硬件故障。

**【VIVO-014】手机系统卡顿，应用启动慢**
- **现象**：桌面滑动卡顿，应用打开速度明显变慢。
- **排查**：清理后台应用和存储空间（保持至少 10% 空闲存储）。在设置 → 运存与存储中查看内存占用。若长期未重启，重启手机释放内存。若仍卡顿，备份数据后恢复出厂设置。

**【VIVO-015】手机无法识别 SIM 卡**
- **现象**：状态栏显示无 SIM 卡或“SIM 卡未插入”。
- **排查**：关机后重新插拔 SIM 卡，清洁金属触点。将该 SIM 卡插入其他手机测试。若其他手机正常，手机卡槽故障；若其他手机也不识别，联系运营商换卡。

**【VIVO-016】手机屏幕触摸漂移，充电时乱跳**
- **现象**：充电时触摸屏自动乱点，拔掉充电器后恢复正常。
- **排查**：使用非原装充电器时，充电纹波干扰触控。更换原装充电器测试。检查插座地线。若仅特定充电器出现，避免使用该充电器。

**【VIVO-017】手机相机闪退**
- **现象**：打开相机应用后立即闪退，或提示“相机被占用”。
- **排查**：重启手机。在设置 → 应用 → 相机中清除缓存和数据。确认是否有其他应用在后台占用相机。若仍闪退，在工程测试模式中测试相机硬件。

**【VIVO-018】手机 Wi-Fi 和蓝牙同时开启时互相干扰**
- **现象**：同时使用 Wi-Fi 和蓝牙时，Wi-Fi 速度下降或蓝牙音频卡顿。
- **排查**：将 Wi-Fi 切换到 5GHz 频段（蓝牙工作在 2.4GHz，两者同频段会干扰）。若路由器不支持 5GHz，尽量缩短手机与路由器距离。更新手机系统到最新版本，厂商可能通过固件优化共存问题。

**【VIVO-019】手机电池健康度下降，续航明显缩短**
- **现象**：电池最大容量低于 80%，日常使用需频繁充电。
- **排查**：在设置 → 电池 → 电池健康中查看最大容量。低于 80% 时，电池老化导致电压不稳，可能出现意外关机。建议前往 vivo 官方服务中心更换原装电池。

**【VIVO-020】手机开机卡在 vivo Logo**
- **现象**：开机后一直显示 vivo Logo，无法进入桌面。
- **排查**：强制重启（电源键 + 音量下键 10 秒）。若仍卡 Logo，进入 Recovery 模式（电源键 + 音量上键）清除缓存分区。若无效，可选择恢复出厂设置（会清除数据）。若 Recovery 也无法进入，需通过官方工具修复系统。

## 七、 三星电视故障排查

**【SAMSUNG-TV-001】电视黑屏但有声音**
- **现象**：屏幕无图像，但音频正常输出，菜单可能也无法显示。
- **排查**：先检查信号源：按遥控器“信号源”键切换 HDMI 接口，或更换 HDMI 线缆。若所有信号源均黑屏有声，长按遥控器电源键 10 秒强制关机后重新开机，重置显示模块通信[reference:20]。若仍黑屏有声，可能是背光模组或 T-Con 板故障，需检修[reference:21]。

**【SAMSUNG-TV-002】电视无法开机，待机灯不亮**
- **现象**：按遥控器或电视上的电源键无反应，指示灯不亮。
- **排查**：检查电源线是否插紧，更换插座测试。拔掉电源线等待 1-2 分钟后重新插上再开机（释放残余电荷）[reference:22]。若指示灯仍不亮，电源板保险丝或电源模块故障。

**【SAMSUNG-TV-003】电视开机后自动关机，反复循环**
- **现象**：开机几秒到几分钟后自动断电，随后又自动开机或不再启动。
- **排查**：检查遥控器是否有按键卡住导致误触发关机。拔掉电源静置 3 分钟后重新上电。若问题持续，电源板电容老化或主板保护机制触发，需送修检测。

**【SAMSUNG-TV-004】电视屏幕出现竖线/横线**
- **现象**：屏幕上出现纵向或横向的彩色/黑色线条，所有信号源下均存在。
- **排查**：截图或拍照后查看——若线条在所有画面中位置固定，屏幕面板或排线（COF）故障，通常需更换屏幕总成。若仅特定信号源出现，检查该设备的线缆和输出设置。

**【SAMSUNG-TV-005】电视无法连接 Wi-Fi**
- **现象**：搜索不到无线网络，或输入密码后连接失败。
- **排查**：确认路由器开启了 2.4GHz 频段（部分三星电视不支持 5GHz）[reference:23]。在电视网络设置中重新搜索并输入密码。重启电视和路由器。检查路由器 MAC 地址过滤。

**【SAMSUNG-TV-006】电视遥控器失灵**
- **现象**：按键无反应，遥控器指示灯不亮。
- **排查**：更换电池（注意正负极）。若为蓝牙遥控器（如 SolarCell 遥控器），需按住“返回”和“播放/暂停”键重新配对。清理遥控器红外发射窗。若遥控器指示灯亮但电视无反应，电视红外接收窗被遮挡或故障。

**【SAMSUNG-TV-007】电视应用商店无法打开，一直转圈**
- **现象**：点击应用商店后无限加载，或提示网络错误。
- **排查**：检查电视网络连接是否正常。将 DNS 改为 `114.114.114.114` 或 `8.8.8.8`。检查电视系统时间是否正确（时间错误会导致证书验证失败）。更新电视系统到最新版本。

**【SAMSUNG-TV-008】电视画面颜色失真（偏红/偏蓝/偏绿）**
- **现象**：画面整体色调异常，或局部颜色错误。
- **排查**：检查 HDMI 线缆是否插紧，更换线缆测试。在图像设置中恢复默认值。若仅在特定信号源下偏色，检查该设备的输出设置。若所有信号源均偏色，面板或 T-Con 板故障。

**【SAMSUNG-TV-009】电视声音和画面不同步**
- **现象**：口型与声音不匹配，音频滞后或超前。
- **排查**：进入声音 → 音效 → 音频延迟，调整延迟数值（通常在 0-100ms 之间）[reference:24]。若使用外接音响/回音壁，检查音响的音频同步设置。若为机顶盒信号，检查机顶盒的 A/V 同步设置。

**【SAMSUNG-TV-010】电视无法识别 U 盘**
- **现象**：插入 U 盘后电视无反应，或提示“不支持的文件系统”。
- **排查**：U 盘格式需为 FAT32 或 NTFS。容量过大（超过 1TB）可能不支持。部分三星电视需在“源”菜单中手动选择 USB。尝试更换 USB 接口。

**【SAMSUNG-TV-011】电视屏幕漏光**
- **现象**：暗色背景下，屏幕四角或边缘出现白色光晕。
- **排查**：液晶面板组装公差导致轻微漏光，属于正常现象。若漏光严重且影响观看，在保修期内可申请换机。调整背光亮度可减轻视觉影响。

**【SAMSUNG-TV-012】电视无法投屏**
- **现象**：手机搜索不到电视，或投屏连接失败。
- **排查**：确保手机和电视连接同一 Wi-Fi。打开电视的“多屏互动”或 AirPlay 功能。部分视频 App 因版权限制禁止投屏。重启电视和手机。

**【SAMSUNG-TV-013】电视开机卡在 Samsung Logo**
- **现象**：开机后一直显示 Samsung Logo，无法进入主界面。
- **排查**：拔掉电源线等待 2 分钟后重新上电。若仍卡 Logo，系统固件可能损坏，需通过 USB 刷写固件或联系售后维修。

**【SAMSUNG-TV-014】电视待机指示灯闪烁，无法开机**
- **现象**：待机灯闪烁（红/白），按电源键无反应。
- **排查**：拔掉电源线等待 1 分钟重新插上。若指示灯仍闪烁，电源板或主板故障，需送修。

**【SAMSUNG-TV-015】电视画面闪烁或出现雪花**
- **现象**：画面间歇性闪烁，或出现雪花噪点。
- **排查**：检查天线信号强度（菜单 → 自诊断 → 信号信息），低于 65% 需调整天线。检查 HDMI 接口是否松动/氧化。若仅无线信号出现，路由器干扰或距离过远。

**【SAMSUNG-TV-016】电视蓝牙音响/耳机无法连接**
- **现象**：搜不到蓝牙设备，或配对失败。
- **排查**：进入声音 → 音效输出 → 蓝牙设备列表，搜索并配对。部分老款三星电视不支持蓝牙音频输出。确认蓝牙设备处于可发现模式。

**【SAMSUNG-TV-017】电视无法通过 HDMI 识别电脑**
- **现象**：电脑连接电视后，电视提示无信号。
- **排查**：电脑上按 `Win + P` 选择“复制”或“扩展”。检查 HDMI 线是否过长（劣质长线信号衰减严重）。更换 HDMI 接口测试。确认电视信号源已切换到对应 HDMI 口。

**【SAMSUNG-TV-018】电视开机后画面卡死，遥控器无响应**
- **现象**：画面停在某一帧，遥控器按键无反应。
- **排查**：长按遥控器电源键 10 秒强制关机，等待 30 秒后重新开机。若频繁卡死，系统固件问题，检查更新或恢复出厂设置。

**【SAMSUNG-TV-019】电视屏幕出现坏点/亮点**
- **现象**：纯色背景下可见持续发光的白点或不发光的黑点。
- **排查**：使用在线屏幕测试工具切换纯色确认坏点。根据三星保修政策，坏点数量超过标准可申请保修。软件无法修复坏点。

**【SAMSUNG-TV-020】电视网络连接正常但无法访问特定应用**
- **现象**：YouTube/Netflix 等应用提示网络错误，但其他应用正常。
- **排查**：检查电视系统时间是否正确（证书验证依赖时间）。将 DNS 改为 `8.8.8.8`。更新该应用到最新版本。若仅特定应用异常，应用服务器或区域限制问题。


## 八、 创维电视故障排查

**【SKYWORTH-001】开机卡在创维 Logo，无法进入主界面**
- **现象**：通电后一直显示创维 Logo，不进入桌面。
- **排查**：拔掉电源线等待 2-3 分钟后重新上电。若仍卡 Logo，尝试强制恢复：拔掉电源，长按电视上的“待机键”（通常在左下角后方）不松手，再插上电源，约 10 秒后松手，进入恢复菜单后选择“清除所有数据”并重启。若恢复菜单无法进入，需通过 USB 刷写固件[reference:26]。

**【SKYWORTH-002】电视黑屏，但指示灯亮**
- **现象**：屏幕不亮，但电源指示灯亮（红色或蓝色）。
- **排查**：按遥控器电源键或电视上的待机键尝试唤醒。检查 HDMI 线缆连接，切换信号源。拔掉电源等待 2 分钟后重试。若仍黑屏，背光模组或电源板故障。

**【SKYWORTH-003】电视开机后自动关机**
- **现象**：开机几秒或几分钟后自动断电，可能反复循环。
- **排查**：检查电源线是否插紧。拔掉电源静置 3 分钟后重新上电。若问题持续，电源板电容老化或主板保护机制触发，需送修。

**【SKYWORTH-004】电视屏幕出现竖线/横线**
- **现象**：屏幕显示纵向或横向线条，重启不消失。
- **排查**：拍照记录线条位置。若所有信号源下线条固定存在，屏幕面板或排线故障，需更换屏幕总成。软件无法修复。

**【SKYWORTH-005】电视无法连接 Wi-Fi**
- **现象**：搜索不到无线网络或连接失败。
- **排查**：确认路由器 2.4GHz 频段开启。重启电视和路由器。在设置中还原网络设置。若其他设备正常，电视 Wi-Fi 模块或系统问题。

**【SKYWORTH-006】电视应用商店/系统应用闪退**
- **现象**：打开应用商店或某个系统应用后立即闪退。
- **排查**：清除该应用的缓存和数据（设置 → 应用管理）。更新电视系统到最新版本。若仅特定应用闪退，卸载后重新安装。若系统应用也闪退，恢复出厂设置[reference:27]。

**【SKYWORTH-007】电视遥控器失灵**
- **现象**：按键无反应，指示灯不亮。
- **排查**：更换电池。若为蓝牙遥控器，重新配对（通常按住“主页”+“菜单”键）。清理遥控器发射窗。若遥控器正常但电视无响应，电视红外接收或蓝牙模块故障。

**【SKYWORTH-008】电视无法识别 U 盘**
- **现象**：插入 U 盘后电视无反应。
- **排查**：U 盘格式需为 FAT32（部分创维电视对 NTFS 支持不完善）。容量过大可能不支持。更换 USB 接口测试。部分电视需在“媒体中心”中手动选择 USB 设备。

**【SKYWORTH-009】电视声音异常（破音/杂音）**
- **现象**：扬声器输出破音、电流声，或声音断续。
- **排查**：检查音量是否过大导致失真。在声音设置中恢复默认值。若外接音响正常但内置扬声器异常，扬声器单元故障。

**【SKYWORTH-010】电视画面颜色失真**
- **现象**：整体偏色或局部颜色异常。
- **排查**：检查 HDMI 线缆。在图像设置中恢复默认。若仅特定信号源偏色，检查该设备输出设置。若所有信号源偏色，面板或 T-Con 板故障。

**【SKYWORTH-011】电视开机后屏幕灰屏/白屏**
- **现象**：开机后屏幕显示灰色或白色，无图像。
- **排查**：拔掉电源等待 2 分钟后重试。检查信号源设备是否正常工作。若所有信号源均灰屏/白屏，屏幕面板或主板故障，需送修。

**【SKYWORTH-012】电视无法投屏**
- **现象**：手机搜索不到电视，或投屏失败。
- **排查**：确保手机和电视同一 Wi-Fi。打开电视的投屏功能（通常在“设置”或“应用”中）。重启电视。部分视频 App 因版权限制禁止投屏。

**【SKYWORTH-013】电视蓝牙无法连接**
- **现象**：搜不到蓝牙设备或配对失败。
- **排查**：确认电视支持蓝牙音频输出。在设置 → 蓝牙中搜索并配对。将蓝牙设备靠近电视。重启电视后重试。

**【SKYWORTH-014】电视系统时间不对**
- **现象**：开机后时间重置或偏差较大。
- **排查**：在设置中开启“自动获取时间”（通过网络同步）。若网络正常但仍不对，手动设置时间。若断电后时间重置，主板纽扣电池可能没电。

**【SKYWORTH-015】电视屏幕漏光**
- **现象**：暗色背景下边缘或四角发白。
- **排查**：轻微漏光属正常现象。若严重影响观看，保修期内可申请换机。

**【SKYWORTH-016】电视开机无反应，指示灯不亮**
- **现象**：按电源键无反应，指示灯熄灭。
- **排查**：检查电源线是否插紧，更换插座。拔掉电源等待 1 分钟后重新插上。若指示灯仍不亮，电源板故障。

**【SKYWORTH-017】电视无法通过 HDMI 识别设备**
- **现象**：连接电脑/机顶盒后无信号。
- **排查**：切换电视信号源到对应 HDMI 口。更换 HDMI 线。检查设备输出分辨率是否在电视支持范围内。

**【SKYWORTH-018】电视画面卡顿、拖影**
- **现象**：运动画面出现拖影或卡顿。
- **排查**：在图像设置中开启“运动补偿”或“MEMC”功能（如有）。检查信号源帧率。若仅网络视频卡顿，检查网络带宽。

**【SKYWORTH-019】电视声音和画面不同步**
- **现象**：口型与声音不匹配。
- **排查**：在声音设置中调整“音频延迟”。若为外接设备，检查设备同步设置。

**【SKYWORTH-020】电视恢复出厂设置后仍卡Logo**
- **现象**：通过恢复菜单执行“清除所有数据”后，开机仍然卡在 Logo。
- **排查**：系统固件损坏较严重，需通过 USB 强制刷机：从创维官网下载对应机型的固件包，放入 FAT32 格式 U 盘根目录，插入电视 USB 口，按住待机键上电触发刷机[reference:28]。若刷机无效，主板存储芯片故障，需送修。


## 九、 海康威视 (Hikvision) 监控系统故障排查

**【HIK-001】NVR 提示“无网络视频”或通道黑屏**
- **现象**：录像机某个通道显示黑屏或“无网络视频”，其他通道正常。
- **排查**：检查对应摄像机是否通电（红外灯是否亮）。检查网线连接和交换机端口指示灯。在 NVR 的“IP 通道”中查看该通道状态——若显示“网络不可达”，检查 IP 地址是否冲突或摄像机离线。

**【HIK-002】NVR 无法识别硬盘，提示“硬盘不存在”或“异常”**
- **现象**：录像机存储管理中显示硬盘离线或异常，无法录像。
- **排查**：断电重启 NVR。检查硬盘数据线和电源线是否插紧。进入硬盘管理尝试格式化。若格式化失败，使用海康 SADP 工具或硬盘厂商工具做 S.M.A.R.T 检测，确认硬盘是否有坏道[reference:29]。

**【HIK-003】回放时搜不到录像文件**
- **现象**：时间轴上没有录像，或提示“无录像文件”。
- **排查**：检查“录像计划”是否配置为定时录像（而非仅移动侦测）。在硬盘管理中查看硬盘状态是否正常，建议做 S.M.A.R.T 检测[reference:30]。检查设备系统时间是否正确，时间错误会导致录像检索错位。若硬盘正常但仍有问题，尝试“硬盘数据库修复”[reference:31]。

**【HIK-004】监控主机报警“硬盘满”，但不自动覆盖**
- **现象**：NVR 持续报警硬盘满，旧录像未被新录像覆盖。
- **排查**：进入存储管理 → 硬盘管理，确认录像模式设置为“循环覆盖”而非“满即停”[reference:32]。若已设为循环覆盖但仍报警，硬盘可能存在逻辑坏道，尝试格式化或更换硬盘。

**【HIK-005】摄像机频繁掉线，画面时有时无**
- **现象**：IP 通道频繁断开又自动恢复，录像不连续。
- **排查**：检查网线水晶头是否氧化（重新压制水晶头）。PoE 交换机总功率是否足够（摄像机数量多时供电不足会导致掉线）。检查 IP 地址是否冲突。更新摄像机固件。

**【HIK-006】监控画面偏色（偏红/偏绿/偏紫）**
- **现象**：摄像机画面颜色异常，其他通道正常。
- **排查**：检查摄像机红外切换滤光片（ICR）是否卡住，夜间切换异常会导致偏色。用手电筒照射镜头测试切换是否动作，若卡住需拆机拨动或更换。强光照射也可能导致传感器暂时性偏色。

**【HIK-007】NVR 无法添加第三方摄像机（ONVIF）**
- **现象**：添加大华/宇视等第三方摄像机时提示“未知错误”或“参数错误”。
- **排查**：确认第三方摄像机已开启 ONVIF 协议，并创建了 ONVIF 用户。在 NVR 中添加时选择 ONVIF 协议，输入正确的 ONVIF 用户名和密码。将摄像机主码流改为 H.264（部分 NVR 对 H.265 兼容性差）。

**【HIK-008】云台摄像机无法转动，控制无反应**
- **现象**：NVR 上操作云台方向键，摄像机无动作。
- **排查**：检查云台电源是否正常。检查 NVR 与云台之间的 RS485 线（A/B 线）是否接反或断路。确认 NVR 中云台协议（如 Pelco-D）和波特率与摄像机一致。若仅单个方向失灵，云台电机或限位故障。

**【HIK-009】监控画面卡顿严重，不流畅**
- **现象**：预览和回放均卡顿，画面一顿一顿。
- **排查**：检查网络带宽——多路高清同时预览可能超出交换机上行带宽，尝试降低子码流分辨率/帧率。检查硬盘是否有坏道导致写入卡顿。在 NVR 中降低预览码流。

**【HIK-010】NVR 设备被锁定，无法登录**
- **现象**：登录界面提示“用户被锁定”。
- **排查**：多次输错密码触发安全锁定，等待 30 分钟后自动解锁。若急需解锁，使用 SADP 软件导出 XML 文件发送给海康售后重置密码，或通过绑定的邮箱/手机号找回[reference:33]。

**【HIK-011】监控画面出现水波纹或横条干扰**
- **现象**：画面有滚动的水波纹或横向干扰纹。
- **排查**：检查视频线缆（模拟系统）是否与强电线路平行走线，保持距离。检查系统接地是否良好。若是网络摄像机，检查 PoE 供电是否纯净，尝试更换 PoE 交换机端口。

**【HIK-012】NVR 无法通过网络访问（局域网/远程）**
- **现象**：浏览器或客户端无法连接 NVR。
- **排查**：检查 NVR 的网络配置（IP、网关、DNS）是否正确。在电脑上 `ping` NVR 的 IP 地址。检查防火墙是否拦截了 NVR 的端口（HTTP 80、服务 8000、RTSP 554）。远程访问需检查路由器端口映射或海康云石/萤石云配置。

**【HIK-013】监控画面白天正常，夜间黑屏**
- **现象**：白天图像正常，天黑后画面全黑，红外灯可能不亮。
- **排查**：摄像机电源功率不足，夜间红外灯开启后供电不足导致传感器不工作。更换功率更大的电源适配器。检查光敏传感器是否被遮挡或故障，导致红外灯不切换。若红外灯亮但画面黑，红外灯板或镜头故障。

**【HIK-014】摄像机画面模糊，无法对焦**
- **现象**：画面整体模糊，远近都无法对焦清晰。
- **排查**：检查摄像机镜头保护膜是否撕掉，镜头是否有灰尘/指纹，用镜头布清洁。若为手动变焦镜头，调整后焦环。若镜头内部起雾，需干燥处理或更换。自动对焦摄像机若对焦马达故障，需返修。

**【HIK-015】NVR 报警“IP 地址冲突”**
- **现象**：NVR 或摄像机提示 IP 地址冲突。
- **排查**：在 NVR 的 IP 通道列表中查看哪些设备使用了相同 IP。将冲突设备改为不同 IP，或启用 DHCP 保留。确保局域网中没有其他设备（如电脑、打印机）占用了摄像机的 IP。

**【HIK-016】录像文件下载后无法播放**
- **现象**：从 NVR 下载的录像用普通播放器打开黑屏。
- **排查**：海康录像通常为专用格式，需使用海康官网的 VSPlayer 播放器。若仍无法播放，检查录像文件是否下载完整（文件大小是否异常小）。部分加密录像需在播放器中输入密码。

**【HIK-017】移动侦测报警不触发**
- **现象**：有人经过画面但无报警、无录像。
- **排查**：在 NVR 中确认移动侦测已启用并绘制了侦测区域。检查“联动方式”是否勾选了录像/上传中心/报警输出。适当提高灵敏度。检查时间段设置是否覆盖当前时间。

**【HIK-018】NVR 时间不准，与实际时间偏差大**
- **现象**：监控画面 OSD 时间与实际时间不符。
- **排查**：在 NVR 系统设置中手动校时，或开启 NTP 自动校时（指向 `ntp.aliyun.com` 或内网 NTP 服务器）。若断电后时间重置，主板电池可能没电。

**【HIK-019】监控画面出现马赛克/花屏**
- **现象**：画面局部出现马赛克方块或花屏。
- **排查**：网络丢包或带宽不足，降低码率/帧率测试。检查网线质量和水晶头是否良好。若仅单通道出现，该摄像机编码模块或网络链路问题。

**【HIK-020】NVR 无法启动，电源灯亮但无显示**
- **现象**：NVR 通电后指示灯亮，但显示器无输出，设备无启动声音。
- **排查**：检查显示器连接线（HDMI/VGA）是否插紧。更换显示器测试。若显示器正常但 NVR 无输出，主板或电源模块故障，需送修。


## 十、 IT 技术支持 / 桌面运维常见故障排查

**【DESK-001】网络打印机显示“脱机”，无法打印**
- **现象**：打印任务发送后无输出，打印机状态显示“脱机”。
- **排查**：在“设备和打印机”中右键打印机 → 取消勾选“脱机使用打印机”[reference:34]。重启 Print Spooler 服务（`services.msc` → Print Spooler → 重启）。`ping` 打印机 IP 确认网络连通。若 IP 不通，重启打印机和路由器。检查打印机 IP 是否变化（DHCP 重新分配），必要时在打印机上设置静态 IP。

**【DESK-002】打印任务卡在队列中，无法取消**
- **现象**：打印队列中有多个任务卡住，无法删除，后续任务也无法打印。
- **排查**：停止 Print Spooler 服务。清空 `C:\Windows\System32\spool\PRINTERS` 目录下的所有文件。重新启动 Print Spooler 服务，队列被清空，重新发送打印任务[reference:36]。

**【DESK-003】共享文件夹无法访问，提示“无权限”或“找不到网络路径”**
- **现象**：`\\IP` 访问共享文件夹时提示无权限或网络路径错误。
- **排查**：确认网络发现和文件共享已开启。检查目标电脑的防火墙是否放行了 SMB（445 端口）。确认输入的用户名和密码正确，且账户有共享权限。若提示“找不到网络路径”，`ping` 目标 IP 确认网络通，检查目标电脑是否开机。

**【DESK-004】电脑无法连接有线网络，网口灯不亮**
- **现象**：插上网线后，网口指示灯不亮，网络图标显示红叉。
- **排查**：更换网线测试。检查交换机/路由器端口是否正常（换端口测试）。在设备管理器中查看网卡是否被禁用或有感叹号，卸载后重启重装驱动。`ipconfig /release` 和 `ipconfig /renew` 重新获取 IP。

**【DESK-005】电脑获取到 169.254.x.x 地址，无法上网**
- **现象**：`ipconfig` 显示 IPv4 地址为 169.254 开头，无法访问网络。
- **排查**：169.254 是 APIPA 地址，表示 DHCP 获取失败。检查网线连接。重启路由器和电脑。在“网络连接”中禁用再启用网卡。若 DHCP 服务器正常，检查交换机端口是否被划分到错误 VLAN。

**【DESK-006】电脑蓝屏，错误代码 MEMORY_MANAGEMENT**
- **现象**：系统蓝屏，错误代码指向内存管理。
- **排查**：运行 Windows 内存诊断（`mdsched.exe`）。若测试报错，更换或重新插拔内存条（清洁金手指）。若内存正常，运行 `sfc /scannow` 和 `DISM` 修复系统文件。检查近期安装的驱动/软件，在安全模式下排查。

**【DESK-007】开机提示 “Bootmgr is missing”**
- **现象**：开机后屏幕显示 “Bootmgr is missing”。
- **排查**：进入 BIOS 确认硬盘被识别且启动顺序正确。使用 Windows 安装 U 盘启动，进入修复模式，在命令提示符中依次执行 `bootrec /fixmbr`、`bootrec /fixboot`、`bootrec /rebuildbcd`。

**【DESK-008】系统时间频繁重置**
- **现象**：每次开机时间都回到默认值，或时间明显偏差。
- **排查**：更换主板 CR2032 纽扣电池。在 Windows 时间设置中手动同步 `time.windows.com`。检查“Windows Time”服务是否启动。若同步失败，检查网络或防火墙是否拦截了 NTP（123 端口）。

**【DESK-009】C 盘空间不足，系统运行缓慢**
- **现象**：C 盘飘红，可用空间极少，系统卡顿。
- **排查**：运行磁盘清理（`cleanmgr`），清理 Windows 更新缓存和临时文件。卸载不用的软件。将虚拟内存/休眠文件转移到其他盘。使用 Dism++ 或 TreeSize 查找大文件。若长期未重装，考虑备份后重装系统。

**【DESK-010】浏览器无法上网，但 QQ/微信正常**
- **现象**：浏览器打不开网页，但即时通讯软件正常。
- **排查**：检查浏览器是否设置了代理（设置 → 网络 → 代理，关闭代理）。将 DNS 改为 `114.114.114.114` 或 `8.8.8.8`。清除浏览器缓存和 Cookie。尝试其他浏览器测试，确认是否仅特定浏览器异常。

**【DESK-011】鼠标/键盘失灵，USB 不识别**
- **现象**：USB 键鼠无反应，或频繁断开重连。
- **排查**：更换 USB 接口（前置口供电弱，优先用后置口）。无线键鼠更换电池或重新对码。在设备管理器中卸载 USB 控制器和键鼠驱动，重启后让系统重装。若仅特定接口异常，接口硬件故障。

**【DESK-012】显示器闪烁或出现水波纹**
- **现象**：显示器画面闪烁，或出现横向水波纹。
- **排查**：检查 VGA/HDMI 线是否插紧，更换线缆测试。VGA 线检查针脚是否弯曲。将显示器远离大功率音箱/变压器（磁场干扰）。调整刷新率到推荐值（如 60Hz）。

**【DESK-013】无法安装软件，提示“权限不足”**
- **现象**：双击安装包后无反应，或提示需要管理员权限。
- **排查**：右键安装包 → “以管理员身份运行”。若组策略限制了安装，联系 IT 部门获取临时权限。确认当前用户账户类型是否为管理员。

**【DESK-014】U 盘无法读取，提示“此设备已被管理员禁用”**
- **现象**：插入 U 盘后提示设备被禁用。
- **排查**：IT 部门可能通过组策略或注册表禁用了 USB 存储设备。提交工单申请临时解禁。检查注册表 `HKLM\SYSTEM\CurrentControlSet\Services\USBSTOR` 的 `Start` 值是否为 4（4=禁用，3=启用）。

**【DESK-015】网页打不开，但 QQ/微信正常**
- **现象**：浏览器无法加载网页，即时通讯正常。
- **排查**：检查 DNS（改为公共 DNS）。关闭浏览器代理。清除浏览器缓存。若仅特定网站异常，检查 hosts 文件是否被修改。尝试 `ping` 域名确认 DNS 解析。

**【DESK-016】耳机插入前面板无声，后面板正常**
- **现象**：前面板耳机孔无声音，后面板正常。
- **排查**：在 Realtek 音频管理器中勾选“禁用前面板插孔检测”。检查前面板音频线是否插在主板正确的 AAudio 跳线针脚上。若前面板硬件损坏，使用后面板或 USB 声卡。

**【DESK-017】电脑开机后风扇噪音大，温度高**
- **现象**：开机后风扇高速运转，机箱/笔记本发热明显。
- **排查**：清理散热风扇和出风口的灰尘。检查 CPU/GPU 导热硅脂是否干涸，重新涂抹。在 BIOS 或厂商控制软件中调整风扇曲线。若风扇轴承磨损，更换风扇。

**【DESK-018】Office 提示激活失败**
- **现象**：Word/Excel 提示产品未激活或激活过期。
- **排查**：确认使用的是公司批量授权版本。检查 KMS 服务器是否可达（`nslookup` KMS 域名或 `ping` KMS IP）。若为 Microsoft 365 账户，重新登录账户。运行 `ospp.vbs /dstatus` 查看激活状态。

**【DESK-019】开机自启软件过多，开机缓慢**
- **现象**：开机后需要很长时间才能正常使用。
- **排查**：任务管理器 → 启动项，禁用不必要的自启软件（如各类全家桶、更新程序）。使用 Autoruns 检查深层自启项。卸载不常用的软件。若仍缓慢，考虑升级 SSD 或增加内存。

**【DESK-020】电脑频繁自动重启或关机**
- **现象**：使用中电脑突然重启或关机，无蓝屏。
- **排查**：检查 CPU/GPU 温度，过热会触发保护关机。检查电源功率是否足够（高功耗显卡需足够瓦数）。运行内存诊断和硬盘健康检测。在“系统属性 → 高级 → 启动和故障恢复”中取消“自动重新启动”，以便看到蓝屏错误信息。

**【DESK-021】无法访问共享打印机，提示“Windows 无法连接到打印机”**
- **现象**：添加网络共享打印机时报错，错误代码 0x0000011b 等。
- **排查**：此错误常见于 Windows 更新后 RPC 认证级别变化。在打印服务器和客户端上检查并调整注册表 `RpcAuthnLevelPrivacyEnabled` 为 0（需谨慎操作）。或使用 IP 直连方式添加打印机（`\\IP\打印机名`）而非通过主机名。确保 Print Spooler 服务运行。

**【DESK-022】电脑连接投影仪后分辨率异常**
- **现象**：连接投影仪后，投影画面分辨率不对，或电脑屏幕黑屏。
- **排查**：按 `Win + P` 切换投影模式（复制/扩展/仅第二屏幕）。在显示设置中调整投影仪的分辨率到其原生分辨率。若投影仪无信号，更换 HDMI/VGA 线，检查投影仪信号源输入。

**【DESK-023】输入法无法切换，或输入中文变英文**
- **现象**：按 Shift 或 Ctrl+Space 无法切换中英文，只能输入英文。
- **排查**：检查输入法是否被禁用（设置 → 时间和语言 → 语言 → 中文 → 选项，确认输入法存在）。按 `Win + Space` 切换输入法。重启输入法进程（`ctfmon.exe`）。若仍异常，删除并重新添加中文输入法。

**【DESK-024】电脑声音异常，有杂音或无声**
- **现象**：扬声器/耳机输出有杂音、电流声，或完全无声。
- **排查**：检查音频线是否插紧，更换接口测试。在声音设置中确认输出设备正确。卸载并重装声卡驱动（Realtek/厂商驱动）。若仅特定应用无声，检查应用音量设置。硬件层面，前置面板音频线干扰或声卡芯片故障。

**【DESK-025】电脑无法识别外接显示器**
- **现象**：通过 HDMI/DP/Type-C 连接显示器后，显示器无信号。
- **排查**：按 `Win + P` 选择“复制”或“扩展”。更换线缆和接口测试。检查显卡驱动是否正常。若使用扩展坞，确认扩展坞支持视频输出。在显示设置中点击“检测”按钮。

**【DESK-026】系统盘 C 盘空间持续减少，清理后很快又满**
- **现象**：C 盘可用空间越来越少，清理后短时间内再次告急。
- **排查**：检查 Windows 更新缓存（`SoftwareDistribution\Download`）、系统还原点、休眠文件、页面文件。使用 WizTree/TreeSize 扫描 C 盘找出大文件/文件夹。检查是否有软件持续生成日志/缓存。关闭 Windows 休眠（`powercfg -h off`）可释放与内存等大的空间。

**【DESK-027】电脑开机后桌面图标全部消失**
- **现象**：开机进入系统后，桌面空白，无任何图标和任务栏。
- **排查**：按 `Ctrl + Shift + Esc` 打开任务管理器，运行新任务 `explorer.exe`。若任务栏和图标恢复，可能是 explorer 进程异常退出。检查近期安装的软件/更新。若反复出现，运行 `sfc /scannow` 修复系统文件。

**【DESK-028】笔记本电池续航突然大幅下降**
- **现象**：原本可用 5-6 小时的笔记本，现在只能用 1-2 小时。
- **排查**：在电池报告中查看设计容量与当前满充容量（`powercfg /batteryreport`）。若满充容量远低于设计容量（低于 80%），电池老化，需更换。检查后台是否有高耗电进程。降低屏幕亮度、关闭蓝牙/Wi-Fi 测试。

**【DESK-029】USB 接口供电不足，外接设备频繁断开**
- **现象**：外接移动硬盘、USB 网卡等设备使用中频繁断开重连。
- **排查**：使用带外部供电的 USB Hub。在设备管理器中取消 USB Root Hub 的“允许计算机关闭此设备以节约电源”。前置 USB 口供电较弱，优先使用后置接口。若仅特定接口异常，该接口供电电路故障。

**【DESK-030】电脑开机提示“CMOS Checksum Error”**
- **现象**：开机自检时报 CMOS Checksum Error，时间重置。
- **排查**：主板纽扣电池（CR2032）电量耗尽。更换电池。进入 BIOS 加载默认设置（F9/Load Defaults），保存退出（F10）。若更换电池后仍报错，CMOS 芯片或主板电路故障。


## 十一、 网络工程师常见故障排查

**【NET-001】局域网内同一 VLAN 下设备互相 ping 不通**
- **现象**：同网段的两台电脑无法互相 ping 通。
- **排查**：检查网线、端口状态（`display interface brief`）。确认交换机端口划分到正确 VLAN。检查是否有 STP 环路导致端口阻塞。检查 ARP 表是否有对应的 MAC 地址。检查终端防火墙是否拦截了 ICMP。

**【NET-002】同一 VLAN 通，跨 VLAN 无法通信**
- **现象**：同网段可互通，不同网段之间 ping 不通。
- **排查**：检查三层交换机/路由器的 VLANIF 接口是否配置 IP 并 `undo shutdown`。检查路由表是否有目标网段路由。检查 ACL 或防火墙是否拦截了跨 VLAN 流量。确认终端网关指向正确。

**【NET-003】网络突然极度卡顿，交换机指示灯狂闪**
- **现象**：全网或部分 VLAN 网络变慢，交换机端口灯高频闪烁，CPU 利用率飙升。
- **排查**：典型二层环路导致的广播风暴。查看交换机 CPU 利用率，使用 `display interface` 查看端口广播包速率是否暴增。开启 STP/RSTP，检查端口角色和状态，找出环路端口并 `shutdown`。检查是否有人私接交换机/路由器形成环路[reference:38]。

**【NET-004】能 ping 通网关，但无法访问外网**
- **现象**：内网通信正常，`ping` 网关通，但无法访问互联网。
- **排查**：检查核心路由器的默认路由是否正确指向运营商网关。检查 NAT 配置是否生效（`display nat session`）。检查 DNS 是否能解析外网域名（`nslookup baidu.com`）。检查出口防火墙策略是否放行。

**【NET-005】Trunk 链路不通，跨交换机 VLAN 通信失败**
- **现象**：多台交换机级联后，不同交换机上的同 VLAN 用户无法通信。
- **排查**：检查 Trunk 端口是否允许对应 VLAN 通过（`port trunk allow-pass vlan all` 或指定 VLAN）。两端封装协议（802.1Q）是否一致。Native VLAN 是否匹配。检查物理链路（光模块/网线）是否正常。

**【NET-006】IP 地址冲突**
- **现象**：网络时断时续，系统提示 IP 地址冲突。
- **排查**：在核心交换机上 `display arp | include <冲突IP>` 找到对应 MAC。通过 `display mac-address` 查找该 MAC 连接在哪个端口。找到私设 IP 的设备（常见为私接路由器）并关闭其 DHCP 服务或修改 IP[reference:39]。

**【NET-007】交换机端口频繁 Up/Down，网络闪断**
- **现象**：端口状态在 up 和 down 之间反复切换，用户网络频繁中断。
- **排查**：检查网线质量和水晶头是否氧化/松动。光模块故障或光纤端面脏污（用无水酒精清洁）。双工模式不匹配（强制全双工 vs 自协商）。端口协商速率不匹配。若端口本身硬件故障，更换端口。

**【NET-008】DHCP 客户端获取不到 IP 地址**
- **现象**：终端获取到 169.254.x.x 地址，无法正常通信。
- **排查**：检查 DHCP 服务器地址池是否耗尽。检查交换机 DHCP Relay（中继）配置是否正确。检查 VLAN 接口下是否绑定了错误的 DHCP 服务器组。在交换机上 `display dhcp server statistics` 查看 DHCP 报文收发情况。

**【NET-009】OSPF 邻居建立不起来**
- **现象**：路由器之间无法建立 OSPF 邻居关系，路由表缺失。
- **排查**：检查 Router ID 是否冲突。检查 Hello 和 Dead 定时器是否一致。检查区域 ID（Area ID）是否相同。检查 MTU 是否匹配（MTU 不一致会导致邻居卡在 ExStart）。检查认证密码是否一致。

**【NET-010】网络丢包严重，ping 不稳定**
- **现象**：`ping` 出现丢包，延迟波动大。
- **排查**：检查端口是否有 CRC 错误（`display interface` 查看 `CRC` 计数）。检查链路带宽是否被占满（`display interface | include rate` 查看流量利用率）。光模块收发功率是否过低。检查是否有广播风暴或环路。

**【NET-011】交换机无法 Telnet/SSH 登录**
- **现象**：远程管理交换机时连接失败。
- **排查**：检查 VTY 线路配置（`user-interface vty 0 4`），确认 `authentication-mode` 和用户名密码配置正确。检查 ACL 是否限制了源 IP 访问 VTY。确认管理 VLAN 和 IP 可达。检查 SSH 版本兼容性。

**【NET-012】MAC 地址漂移**
- **现象**：交换机日志持续报警 MAC 地址漂移，同一 MAC 出现在多个端口。
- **排查**：通常由二层环路、链路捆绑（Eth-Trunk）配置错误或 ARP 欺骗病毒导致[reference:40]。检查 STP 状态，排查环路。检查 Eth-Trunk 成员端口配置是否一致。在终端上安装杀毒软件排查 ARP 欺骗。

**【NET-013】光纤链路不通，光口指示灯不亮**
- **现象**：光纤连接后，两端光口指示灯均不亮。
- **排查**：检查光纤收发端是否接反（TX 接 RX，RX 接 TX）。使用光功率计测试发送功率和接收灵敏度是否在正常范围。清洁光纤端面（无水酒精）。检查光模块是否与交换机兼容。

**【NET-014】VLAN 间通信被 ACL 阻断**
- **现象**：配置 ACL 后，部分网段之间无法互访。
- **排查**：检查 ACL 规则的匹配顺序（自上而下匹配，默认拒绝）。确认是否放行了回程流量。检查 ACL 应用的方向（inbound/outbound）和接口是否正确。使用 `display acl` 查看规则命中计数。

**【NET-015】无线网络信号弱，连接不稳定**
- **现象**：Wi-Fi 信号强度低，频繁掉线或速率慢。
- **排查**：检查 AP 发射功率设置。检查信道干扰（使用 Wi-Fi 分析仪，2.4GHz 固定 1/6/11 信道）。检查终端是否在 AP 覆盖边缘。AP 接入用户数是否超限。调整 AP 位置或增加 AP。

**【NET-016】无线终端无法获取 IP 地址**
- **现象**：连上 Wi-Fi 但无法上网，获取不到 IP。
- **排查**：检查无线控制器的 DHCP 中继配置。检查 AP 的管理 VLAN 和业务 VLAN 配置是否正确。检查是否开启了 MAC 地址认证且终端未通过。检查无线信号加密方式与终端兼容性。

**【NET-017】端口安全（Port-Security）导致断网**
- **现象**：用户更换电脑或网卡后，插上网线无法联网，端口 err-disabled。
- **排查**：交换机端口配置了 `port-security` 并绑定了原 MAC 地址。新 MAC 不匹配触发端口禁用。进入接口 `shutdown` 再 `undo shutdown` 恢复，或清除 MAC 绑定/重新绑定新 MAC。

**【NET-018】路由环路**
- **现象**：数据包在路由器之间循环，`tracert` 显示 TTL 超时。
- **排查**：检查静态路由的下一跳是否指向自身或形成环路。检查动态路由协议的防环机制（水平分割、毒性逆转）是否开启。检查路由汇总是否产生了环路。

**【NET-019】VPN 连接成功但无法访问内部服务器**
- **现象**：拨上 VPN 后，能 ping 通 VPN 网关，但访问不了内网服务器。
- **排查**：检查 VPN 客户端的路由表，是否缺少目标内网网段的路由（拆分隧道配置问题）。检查防火墙 VPN 策略是否放行了到内网服务器的流量。检查内网服务器自身的防火墙是否拦截了 VPN 地址池。

**【NET-020】网络设备 CPU 占用率极高**
- **现象**：交换机/路由器管理界面卡顿，业务转发性能下降。
- **排查**：是否有广播风暴（检查端口广播包速率）。是否有针对设备的攻击（如 ARP 攻击、ICMP Flood）。开启了大量 Debug 调试信息。使用 `display cpu-usage` 查看哪个进程占用 CPU 最高，针对性处理。

**【NET-021】交换机端口聚合（Eth-Trunk）不生效**
- **现象**：配置了链路聚合，但带宽未叠加，或聚合口状态异常。
- **排查**：检查两端 Eth-Trunk 模式是否一致（手工负载分担/LACP）。检查成员端口的速率、双工、VLAN 配置是否完全一致。LACP 模式下检查系统优先级和端口优先级。物理链路是否全部 Up。

**【NET-022】无线漫游时断流**
- **现象**：终端在 AP 之间移动时，视频通话/游戏出现短暂断流。
- **排查**：检查 AP 间的信号覆盖重叠区域是否足够。确认所有 AP 的 SSID、加密方式、VLAN 配置一致。开启快速漫游（802.11r/k/v）。同频干扰严重时调整信道规划。

**【NET-023】网关设备 ARP 表项异常**
- **现象**：核心交换机 ARP 表出现大量不完整或错误表项，网络不稳定。
- **排查**：可能有 ARP 欺骗或扫描攻击。检查对应 MAC 的端口，定位攻击源。开启 DAI（动态 ARP 检测）和 DHCP Snooping。在终端上安装杀毒软件。

**【NET-024】STP 拓扑震荡，端口频繁阻塞/转发**
- **现象**：网络间歇性中断，STP 日志显示拓扑变更频繁。
- **排查**：检查是否存在物理环路或单向链路故障。检查 STP 边缘端口（PortFast）是否配置在正确的接入端口上。检查 BPDU 保护/根保护是否配置。更换故障网线/光模块。

**【NET-025】DNS 解析超时或失败**
- **现象**：`ping` 域名失败，但 `ping` IP 地址正常。
- **排查**：检查终端 DNS 设置。检查 DNS 服务器可达性（`nslookup` 指定 DNS 服务器）。检查防火墙是否拦截了 DNS（53 端口）。若使用内部 DNS，检查 DNS 转发器配置和区域记录。

**【NET-026】交换机端口镜像（SPAN）不生效**
- **现象**：配置了端口镜像，但抓包工具收不到流量。
- **排查**：检查源端口和目的端口配置是否正确。确认目的端口没有启用其他功能（如 STP、VLAN 过滤）。检查镜像方向（ingress/egress/both）。部分交换机不支持跨 VLAN 镜像。

**【NET-027】静态路由配置后不生效**
- **现象**：添加静态路由后，目标网段仍然不可达。
- **排查**：检查下一跳 IP 是否可达（`ping` 下一跳）。检查出接口配置是否正确。检查路由优先级（preference）是否低于其他路由。使用 `display ip routing-table` 查看路由是否被加入。

**【NET-028】交换机无法通过 Console 登录**
- **现象**：使用 Console 线连接交换机，终端无输出。
- **排查**：检查 Console 线驱动是否安装（USB 转串口）。确认终端软件波特率设置为 9600、数据位 8、停止位 1、无校验。检查 Console 线是否损坏。尝试重启交换机后再连接。

**【NET-029】无线 AP 频繁重启**
- **现象**：AP 指示灯反复熄灭又亮起，无线网络中断。
- **排查**：检查 PoE 供电是否稳定（PoE 交换机端口功率是否足够，网线是否过长导致压降过大）。检查 AP 固件版本，升级到稳定版。检查 AP 是否过热。

**【NET-030】三层交换机 VLANIF 接口无法 ping 通**
- **现象**：VLANIF 接口配置了 IP，但无法 ping 通该接口。
- **排查**：检查 VLANIF 接口是否 `undo shutdown`。检查 VLAN 内是否有物理端口 Up 且划分到该 VLAN。检查是否有 ACL 拦截了 ICMP。检查交换机是否开启了 `icmp echo-reply disable`。


## 十二、 运维工程师常见故障排查

**【OPS-001】服务器 CPU 使用率 100%**
- **现象**：CPU 跑满，业务响应缓慢。
- **排查**：`top` 找到占用最高的进程 PID。`top -H -p <PID>` 查看哪个线程占用高。Java 应用用 `jstack <PID> > stack.log` 分析线程栈，排查死循环或锁竞争。检查是否有异常定时任务或挖矿病毒（`kdevtmpfsi` 等）。

**【OPS-002】服务器内存耗尽（OOM）**
- **现象**：内存耗尽，系统触发 OOM Killer 杀死进程，或服务被强制终止。
- **排查**：`free -h` 查看内存使用，`ps aux --sort=-%mem | head` 找出内存大户。`vmstat 1` 观察内存变化。检查应用是否存在内存泄漏。查看 `/var/log/messages` 或 `dmesg` 是否有 OOM 记录。必要时增加内存或限制应用内存上限。

**【OPS-003】磁盘空间已满（No space left on device）**
- **现象**：无法写入文件或日志，服务报错。
- **排查**：`df -h` 查看已满分区。`du -sh /* | sort -nr` 逐层定位大文件夹。`lsof +L1` 查找已删除但未释放空间的文件（重启对应进程释放）[reference:42]。`df -i` 检查 inode 是否耗尽。

**【OPS-004】磁盘 I/O 负载极高（IO Wait 高）**
- **现象**：系统卡顿，`top` 中 `wa` 值很高，业务响应慢。
- **排查**：`iostat -x 1` 查看哪个磁盘 `%util` 被占满。`iotop` 查看哪个进程在大量读写。检查是否有大型日志轮转、数据库备份任务在跑。检查磁盘是否有坏道（`dmesg` 中的 I/O error）。

**【OPS-005】系统负载（Load Average）很高，但 CPU 空闲**
- **现象**：`uptime` 显示 load average 很高，但 CPU 使用率不高。
- **排查**：通常有大量进程卡在 `D` 状态（不可中断睡眠），等待 I/O。`ps aux | awk '$8 ~ /D/'` 找出 D 状态进程。检查 NFS 挂载是否掉线、磁盘是否有故障。`vmstat 1` 查看 `b` 列（阻塞进程数）。

**【OPS-006】Nginx 报 502 Bad Gateway**
- **现象**：访问网站报 502 错误。
- **排查**：Nginx 连不上后端服务。检查后端服务（Tomcat/PHP-FPM/Python）是否存活（`systemctl status`）。检查 `proxy_pass` 地址和端口是否正确。检查后端服务是否因超时/连接池满而拒绝连接。查看 Nginx `error.log` 中的 `connect() failed` 信息[reference:43]。

**【OPS-007】Nginx 报 504 Gateway Timeout**
- **现象**：页面长时间加载后报 504。
- **排查**：后端处理超时。检查后端程序是否卡死或响应慢。检查 Nginx 配置中的 `proxy_read_timeout` 和 `proxy_connect_timeout` 是否过短。检查网络延迟和后端数据库慢查询[reference:44]。

**【OPS-008】MySQL 连接数满了（Too many connections）**
- **现象**：应用无法连接数据库，报“Too many connections”。
- **排查**：登录 MySQL，`show processlist` 查看卡住的查询和睡眠连接。`kill` 掉 Sleep 时间过长的连接。加大 `max_connections` 参数。检查应用连接池配置是否未正确释放连接。

**【OPS-009】Redis 响应变慢或超时**
- **现象**：接口响应变慢，Redis 操作超时。
- **排查**：`redis-cli --latency` 测试延迟。`info` 查看内存碎片率、连接数。`redis-cli --bigkeys` 扫描大 key。`slowlog get` 查看慢查询。检查是否有持久化阻塞或网络问题。

**【OPS-010】Java 应用频繁 Full GC**
- **现象**：应用卡顿，监控显示 Full GC 频繁，STW 时间长。
- **排查**：`jstat -gcutil <PID> 1000` 观察 GC 频率和耗时。`jmap -dump:format=b,file=heap.hprof <PID>` 导出堆快照，用 MAT 分析内存泄漏对象。检查是否有大量大对象未释放或缓存无上限。

**【OPS-011】服务器 SSH 连接不上**
- **现象**：终端无法 SSH 登录服务器。
- **排查**：`ping` 服务器 IP 确认网络通。`telnet <IP> 22` 测试端口是否开放。检查服务器防火墙（`iptables -L` / `firewall-cmd --list-all`）。检查 SSH 服务（`systemctl status sshd`）是否运行。检查是否因多次密码错误被 Fail2ban 封禁。

**【OPS-012】应用日志报 “Connection refused”**
- **现象**：应用无法连接外部服务。
- **排查**：目标服务未启动或端口未监听。`ss -lntp | grep <端口>` 检查。检查目标 IP 和端口是否正确。检查防火墙是否拦截。检查目标服务是否绑定了 127.0.0.1 而非 0.0.0.0（导致远程无法访问）。

**【OPS-013】应用日志报 “No route to host”**
- **现象**：网络不可达。
- **排查**：目标 IP 不在同一网段且无路由可达。`ip route` 检查路由表。检查目标机器是否宕机。检查中间网络设备（交换机/路由器）配置或 ACL。

**【OPS-014】Docker 容器启动后立刻退出**
- **现象**：`docker ps` 看不到容器，`docker ps -a` 显示状态为 Exited。
- **排查**：`docker logs <容器ID>` 查看启动报错。检查主进程是否在前台运行（PID 1）。检查 Dockerfile 中的 `CMD`/`ENTRYPOINT` 是否正确。检查端口是否被占用或依赖服务未就绪。

**【OPS-015】Docker 容器内无法访问外网**
- **现象**：容器内 `ping` 外网不通。
- **排查**：检查宿主机是否能上网。检查 Docker 的 `daemon.json` 和网桥配置。检查容器启动时是否使用了 `--network none`。检查 iptables 的 NAT 转发规则是否被改动（`iptables -t nat -L`）。

**【OPS-016】Kubernetes Pod 一直处于 CrashLoopBackOff**
- **现象**：Pod 反复重启，无法进入 Running 状态。
- **排查**：`kubectl logs <pod> --previous` 查看上一次崩溃日志。`kubectl describe pod <pod>` 查看事件（Events）。检查 Liveness Probe 配置是否过于激进（超时时间过短）。检查内存 limit 是否过小导致 OOMKilled。

**【OPS-017】服务器被植入挖矿病毒**
- **现象**：CPU 跑满，出现陌生进程（如 `kdevtmpfsi`、随机字符串进程）。
- **排查**：`top` 定位异常进程。检查 `crontab -l` 是否有恶意定时任务。检查 `~/.ssh/authorized_keys` 是否被添加陌生公钥。`chattr +i` 锁定关键文件，清理病毒，修改所有密码，检查是否有其他后门。

**【OPS-018】SSL 证书过期**
- **现象**：浏览器访问提示“连接不安全”或“证书已过期”。
- **排查**：`openssl s_client -connect 域名:443` 查看证书有效期。更新证书文件并重载 Nginx（`nginx -s reload`）。配置证书到期监控告警。

**【OPS-019】Nginx 报 “Too many open files”**
- **现象**：Nginx 无法处理新连接，日志报 Too many open files。
- **排查**：Linux 文件句柄限制不够。在 `limits.conf` 中增大 `nofile`，在 `nginx.conf` 中增大 `worker_rlimit_nofile` 和 `worker_connections`。`ulimit -n` 查看当前限制。

**【OPS-020】服务器时间不同步导致服务异常**
- **现象**：集群节点时间不一致，证书校验失败或日志时间错乱。
- **排查**：检查 `chronyd` 或 `ntpd` 服务是否运行。配置 NTP 客户端同步内部 NTP 服务器或公网源（`ntp.aliyun.com`）。`chronyc sources` 查看同步状态。手动同步 `ntpdate`。

**【OPS-021】数据库主从复制延迟**
- **现象**：从库数据落后于主库，`Seconds_Behind_Master` 值持续增大。
- **排查**：检查主库写入压力是否过大。检查从库硬件性能（CPU/IO）是否不足。检查网络延迟。检查是否有大事务或 DDL 操作阻塞复制。`SHOW PROCESSLIST` 查看从库 SQL 线程状态。

**【OPS-022】服务器磁盘 inode 耗尽**
- **现象**：`df -h` 显示有空间，但无法创建新文件，报 `No space left on device`。
- **排查**：`df -i` 查看 inode 使用率[reference:45]。`du --inode` 或 `find / -xdev -type f | wc -l` 统计文件数量。常见于邮件队列、会话文件、缓存目录、`node_modules` 等海量小文件场景。清理小文件或迁移到新分区。

**【OPS-023】删除大文件后 `df` 空间未释放**
- **现象**：`rm` 删除了大日志文件，但 `df -h` 显示空间未减少。
- **排查**：有进程仍持有已删除文件的句柄。`lsof | grep deleted` 找到对应进程，重启该进程释放空间[reference:46]。或 `> /proc/<PID>/fd/<fd>` 清空文件（不推荐，优先重启）。

**【OPS-024】Nginx 反向代理 WebSocket 连接失败**
- **现象**：WebSocket 连接经过 Nginx 后无法建立。
- **排查**：Nginx 配置中需添加 `proxy_http_version 1.1`、`proxy_set_header Upgrade $http_upgrade`、`proxy_set_header Connection "upgrade"`。检查后端 WebSocket 服务是否正常。检查超时时间设置。

**【OPS-025】Docker 容器 DNS 解析失败**
- **现象**：容器内 `ping` 域名失败，但 `ping` IP 正常。
- **排查**：检查宿主机的 `/etc/resolv.conf`。在 `docker run` 时指定 `--dns 8.8.8.8`。检查 Docker 自定义网络的 DNS 配置。若使用 Docker Compose，检查 `dns` 配置项。

**【OPS-026】Kubernetes Service 无法访问**
- **现象**：通过 Service IP/域名无法访问后端 Pod。
- **排查**：`kubectl get endpoints <service>` 检查 Endpoints 是否有 Pod IP。检查 Pod 的 Readiness Probe 是否通过（未就绪的 Pod 不会加入 Endpoints）。检查 kube-proxy 是否正常运行。检查 NetworkPolicy 是否拦截流量。

**【OPS-027】MySQL 慢查询导致业务卡顿**
- **现象**：业务间歇性卡顿，数据库 CPU 飙高。
- **排查**：开启慢查询日志（`slow_query_log=ON`，`long_query_time=2`）。`mysqldumpslow` 或 `pt-query-digest` 分析慢查询。`EXPLAIN` 分析执行计划，检查是否走索引。优化 SQL 或添加索引。

**【OPS-028】Redis 内存占用持续增长**
- **现象**：Redis 内存使用量不断上升，接近 maxmemory 限制。
- **排查**：`info memory` 查看 `used_memory` 和 `mem_fragmentation_ratio`。`--bigkeys` 扫描大 key。检查是否有未设置过期时间的 key。确认淘汰策略（`maxmemory-policy`）是否合理。

**【OPS-029】服务器磁盘 I/O 错误**
- **现象**：`dmesg` 中出现 I/O error、ata 错误或文件系统只读。
- **排查**：`dmesg | grep -i error` 查看磁盘相关错误。检查 SMART 信息（`smartctl -a /dev/sdX`）。若磁盘出现坏道，尽快备份数据并更换磁盘。文件系统自动 remount 为只读时，检查 `/var/log/messages`。

**【OPS-030】Docker Compose 服务依赖未就绪导致启动失败**
- **现象**：`docker compose up` 后，应用容器启动失败，日志显示连不上数据库。
- **排查**：`depends_on` 仅保证启动顺序，不保证服务就绪。使用 `condition: service_healthy` 配合 `healthcheck`，让应用等数据库健康后再启动[reference:47]。或在应用代码中实现连接重试逻辑。


## 十三、 Linux 运维工程师故障排查

**【LNX-001】`df -h` 有空间但无法写入文件（inode 耗尽）**
- **现象**：提示 `No space left on device`，但 `df -h` 显示分区未满。
- **排查**：`df -i` 查看 inode 使用率，极大概率 inode 耗尽[reference:48]。常见于 `/var/spool/postfix` 邮件队列、会话文件、缓存目录、`node_modules`。清理小文件或迁移目录。

**【LNX-002】删除大文件后 `df` 空间未释放**
- **现象**：`rm` 删除了大日志，但 `df -h` 空间不减少。
- **排查**：`lsof | grep deleted` 找到仍持有文件句柄的进程。重启该进程释放空间。或 `: > /proc/<PID>/fd/<fd>` 清空（优先重启）[reference:49]。

**【LNX-003】`kill -9` 无法杀死进程**
- **现象**：进程状态为 `D` 或 `Z`，`kill -9` 无效。
- **排查**：`D` 状态（不可中断睡眠）：进程在等待 I/O（磁盘/NFS），信号无法送达，需等 I/O 完成或修复存储。`Z` 状态（僵尸）：子进程已死但父进程未回收，需杀死父进程让 init 收养。

**【LNX-004】系统日志 `/var/log/messages` 被写满**
- **现象**：根分区被日志占满，服务无法写入。
- **排查**：检查 `rsyslog`/`syslog-ng` 配置。配置 `logrotate` 进行日志轮转（按大小/时间切割，保留 N 份）。排查是否有程序在疯狂报错（内核错误、硬件故障、应用异常）。

**【LNX-005】修改 `/etc/fstab` 后重启进入 emergency mode**
- **现象**：系统无法正常启动，进入紧急模式。
- **排查**：`fstab` 写错或挂载的磁盘/网络存储不可达。在紧急模式中输入 root 密码，编辑 `fstab`，注释掉错误的挂载项，`mount -o remount,rw /` 后重启。

**【LNX-006】SSH 密钥登录失效，总是提示输入密码**
- **现象**：配置了免密登录但无效，仍需密码。
- **排查**：`~/.ssh/authorized_keys` 权限必须为 600，`~/.ssh` 目录为 700。`/etc/ssh/sshd_config` 中 `PubkeyAuthentication yes`。SELinux 可能阻止读取（`restorecon -R ~/.ssh`）。检查家目录权限不能为 777。

**【LNX-007】`sudo` 提示 “user is not in the sudoers file”**
- **现象**：普通用户无法使用 sudo 提权。
- **排查**：切换到 root，`visudo` 编辑，在 `root ALL=(ALL) ALL` 下方添加 `用户名 ALL=(ALL) ALL`。确保用户属于 `wheel` 组（CentOS/RHEL）或 `sudo` 组（Ubuntu/Debian）。

**【LNX-008】端口被占用，服务无法启动**
- **现象**：服务启动报 `Address already in use`。
- **排查**：`ss -lntp | grep <端口>` 或 `netstat -lntp` 找到占用进程 PID。`kill` 该进程，或修改新服务的端口。检查是否有残留进程或僵尸服务。

**【LNX-009】Cron 定时任务没有执行**
- **现象**：到了设定时间，脚本没有运行。
- **排查**：检查 `crond`/`cron` 服务是否运行。脚本是否有执行权限。脚本内命令是否使用绝对路径（Cron 的 PATH 极简）。检查 `/var/log/cron` 或 `/var/log/syslog` 中的 cron 日志。检查环境变量差异（Cron 中不加载 `.bashrc`）。

**【LNX-010】忘记 root 密码**
- **现象**：无法登录系统。
- **排查**：重启进入 GRUB 菜单，编辑内核启动参数，在 `linux` 行末尾添加 `rd.break`（CentOS/RHEL）或 `init=/bin/bash`（Ubuntu）。挂载根分区为读写（`mount -o remount,rw /sysroot`），`chroot /sysroot`，`passwd root`。SELinux 需创建 `.autorelabel` 文件。

**【LNX-011】`tar` 解压报 “Unexpected EOF”**
- **现象**：解压失败，提示文件不完整。
- **排查**：压缩包在传输中损坏（FTP 未用二进制模式）或下载不完整。重新下载/传输。检查磁盘空间是否不足导致写入中断。`gzip -t` 或 `bzip2 -t` 测试压缩包完整性。

**【LNX-012】`find` 命令查找文件极慢**
- **现象**：在大目录中 `find` 卡住或耗时极长。
- **排查**：限制搜索深度（`-maxdepth`）。排除不需要搜索的目录（如 `-path ./proc -prune`）。查找文件内容优先用 `rg`（ripgrep）而非 `grep -r`。避免在 NFS 挂载点上执行全盘 find。

**【LNX-013】用户登录后立刻被踢出（Shell 损坏）**
- **现象**：输入密码后连接立即断开。
- **排查**：用户的默认 Shell（如 `/bin/bash`）被误删或损坏。通过 root 登录，检查 `/etc/passwd` 中该用户的 Shell 路径。重新安装 bash（`yum install bash` / `apt install bash`）或临时改为 `/bin/sh`。

**【LNX-014】`yum`/`apt` 安装软件报依赖冲突**
- **现象**：包管理器无法安装，提示依赖冲突或版本不兼容。
- **排查**：清理缓存（`yum clean all` / `apt clean`）。更新源（`yum update` / `apt update`）。`yum deplist` / `apt-cache depends` 查看依赖。尝试 `--skip-broken` 跳过冲突包（不推荐长期使用）。手动下载 RPM/DEB 强制安装。

**【LNX-015】文件系统损坏，提示 “Structure needs cleaning”**
- **现象**：无法访问目录，`dmesg` 显示文件系统错误。
- **排查**：通常因非正常关机导致。卸载该分区（`umount /dev/sdX`），`fsck -y /dev/sdX` 修复。若无法卸载，进入单用户模式或 LiveCD 修复。修复前备份数据。

**【LNX-016】`ping` 外部域名提示 “Name or service not known”**
- **现象**：DNS 解析失败，但 `ping` IP 正常。
- **排查**：`/etc/resolv.conf` 中添加 `nameserver 114.114.114.114`。检查网卡配置中的 DNS。`/etc/nsswitch.conf` 中 `hosts: files dns`。`systemctl restart systemd-resolved`（若使用）。

**【LNX-017】`rm -rf` 误删文件，想要恢复**
- **现象**：重要文件被误删除。
- **排查**：立即停止对该分区的写入。若文件仍被进程占用，在 `/proc/<PID>/fd` 中查找。未占用时，卸载分区，使用 `extundelete`（ext3/4）或 `testdisk` 尝试恢复。**切勿向该分区写入任何新数据**。

**【LNX-018】无法切换到 root，提示 “Authentication failure”**
- **现象**：`su -` 输入正确密码仍失败。
- **排查**：`/etc/pam.d/su` 中可能限制了只有 `wheel` 组才能 `su`。将用户加入 `wheel` 组。PAM 模块配置错误需检查 `/var/log/secure` 中的详细报错。

**【LNX-019】系统启动卡在 “A start job is running for...”**
- **现象**：开机卡住 90 秒以上，等待某个 systemd 服务超时。
- **排查**：查看提示的服务名称。`systemctl disable` 不需要的服务。常见于网络等待（`NetworkManager-wait-online`）或 `/etc/fstab` 中挂载的网络存储断开。配置 `x-systemd.device-timeout` 缩短超时。

**【LNX-020】`grep` 搜索中文文件显示乱码**
- **现象**：中文内容在终端中显示为乱码或问号。
- **排查**：`file -i filename` 检查文件编码（可能是 GBK）。`iconv -f gbk -t utf-8 filename` 转换后 `grep`。设置终端 `LANG=en_US.UTF-8` 或 `zh_CN.UTF-8`。

**【LNX-021】`df` 和 `du` 结果不一致**
- **现象**：`df` 显示分区快满了，但 `du` 统计的总量远小于分区大小。
- **排查**：`lsof | grep deleted` 查找已删除但句柄未释放的文件（空间被占用但 `du` 统计不到）。重启占用进程释放空间[reference:50]。

**【LNX-022】`systemctl start` 启动服务超时**
- **现象**：服务启动命令卡住，最终报超时失败。
- **排查**：`systemctl status <服务>` 查看状态和日志。`journalctl -u <服务> -xe` 查看详细错误。检查服务脚本是否阻塞（前台运行未退出）、依赖的服务是否未就绪、端口是否被占用。

**【LNX-023】SSH 连接缓慢，登录需要等待很久**
- **现象**：`ssh` 连接建立慢，输入密码前卡住 10-30 秒。
- **排查**：`/etc/ssh/sshd_config` 中设置 `UseDNS no`（DNS 反向解析慢）。检查 `GSSAPIAuthentication` 是否开启导致延迟，可设为 `no`。网络延迟或防火墙导致握手慢。

**【LNX-024】`crontab` 中的脚本执行失败，但手动执行正常**
- **现象**：手动运行脚本没问题，但 cron 调度时失败。
- **排查**：Cron 环境变量与登录 Shell 不同。脚本中使用绝对路径，或在脚本开头 `source /etc/profile` 和 `source ~/.bashrc`。在脚本中显式设置 `PATH`。将 cron 任务的输出重定向到日志文件排查报错。

**【LNX-025】`iptables` 规则不生效**
- **现象**：添加了防火墙规则，但流量仍然未被拦截或放行。
- **排查**：检查规则是否被插入到正确的链（INPUT/FORWARD/OUTPUT）和位置（`-I` vs `-A`）。检查是否有 Docker 或其他工具修改了 `iptables` 规则（Docker 会自动管理 NAT 规则）。`iptables -L -n -v` 查看规则命中计数。

**【LNX-026】`systemd` 服务自动重启但找不到原因**
- **现象**：服务频繁重启，`journalctl` 中只有重启记录。
- **排查**：检查 `Restart=` 和 `RestartSec=` 配置。`journalctl -u <服务> -b --no-pager` 查看本次启动的完整日志。检查服务进程是否因 OOM、段错误或未捕获异常而退出（退出码非 0）。

**【LNX-027】`yum`/`apt` 安装时报 “Could not resolve host”**
- **现象**：包管理器无法解析软件源域名。
- **排查**：检查 `/etc/resolv.conf` 中的 DNS 设置。`ping mirrors.aliyun.com` 测试域名解析和网络连通性。检查 `/etc/yum.repos.d/` 或 `/etc/apt/sources.list` 中的源地址是否可达。代理环境下需配置包管理器的代理。

**【LNX-028】文件被锁定，无法修改（`Operation not permitted`）**
- **现象**：`rm` 或 `vim` 文件时报 `Operation not permitted`，即使是 root 用户。
- **排查**：`lsattr filename` 查看是否有 `i`（immutable，不可修改）或 `a`（append-only）属性。`chattr -i filename` 移除不可变属性。SELinux 也可能阻止操作（`ls -Z` 查看上下文）。

**【LNX-029】磁盘 `read-only file system`**
- **现象**：文件系统变为只读，无法写入任何文件。
- **排查**：`dmesg | grep -i error` 查看文件系统错误。通常是磁盘 I/O 错误或文件系统损坏触发了自动 remount 只读。检查 SMART（`smartctl`）。`mount -o remount,rw /` 尝试重新挂载，若失败需 `fsck` 修复。

**【LNX-030】`systemd-journald` 占用大量磁盘空间**
- **现象**：`/var/log/journal` 目录持续增大，占用数 GB 空间。
- **排查**：`journalctl --disk-usage` 查看占用。`journalctl --vacuum-size=500M` 或 `--vacuum-time=7d` 清理旧日志。在 `/etc/systemd/journald.conf` 中设置 `SystemMaxUse=500M` 限制最大占用。


## 十四、 Python 程序员故障排查

**【PY-001】`ModuleNotFoundError: No module named 'xxx'`**
- **现象**：运行脚本时报模块找不到，但 `pip install` 显示已安装。
- **排查**：确认 `python` 和 `pip` 是同一环境：`which python`、`which pip`、`python -m pip list`。使用 `python -m pip install xxx` 代替裸 `pip install`[reference:51]。检查虚拟环境是否已激活。`python -c "import xxx; print(xxx.__file__)"` 确认模块实际加载路径。

**【PY-002】`ImportError: cannot import name 'xxx' from 'yyy'`**
- **现象**：模块存在，但导入特定名称失败。
- **排查**：可能是版本不兼容（`yyy` 版本过旧/过新，不包含 `xxx`）。`pip show yyy` 查看版本。检查是否存在同名文件遮蔽（当前目录有 `yyy.py` 覆盖了库）。`pip check` 检查依赖冲突[reference:52]。

**【PY-003】`IndentationError: expected an indented block`**
- **现象**：缩进错误，代码无法运行。
- **排查**：检查报错行及上一行的缩进。Python 要求代码块内统一缩进（通常 4 个空格）。混用 Tab 和空格会导致缩进错误，配置编辑器将 Tab 转为空格。

**【PY-004】`SyntaxError: 'return' outside function`**
- **现象**：`return` 语句不在函数内部。
- **排查**：检查 `return` 的缩进层级，确保它在 `def` 函数体内。常见于复制代码时缩进丢失。

**【PY-005】`TypeError: 'NoneType' object is not subscriptable`**
- **现象**：对 `None` 进行索引/切片操作。
- **排查**：检查上一步的函数返回值是否为 `None`。`dict.get()` 在键不存在时默认返回 `None`，需提供默认值（`.get(key, {})`）。函数在没有 `return` 时默认返回 `None`。

**【PY-006】`KeyError: 'xxx'`**
- **现象**：字典访问不存在的键。
- **排查**：使用 `dict.get(key, default)` 安全获取。`if key in dict` 先判断。`collections.defaultdict` 自动提供默认值。避免直接 `dict[key]` 访问不确定存在的键。

**【PY-007】`IndexError: list index out of range`**
- **现象**：列表索引越界。
- **排查**：`len(lst)` 确认列表长度。使用 `lst[-1]` 访问最后一个元素前确认列表非空。循环中使用 `enumerate` 或 `range(len(lst))` 时注意边界。

**【PY-008】`AttributeError: 'NoneType' object has no attribute 'xxx'`**
- **现象**：对 `None` 调用方法或访问属性。
- **排查**：检查链式调用中上一步的返回值。函数可能在某些分支没有返回有效对象。使用 `if obj is not None` 判空后再调用。

**【PY-009】`ValueError: invalid literal for int() with base 10`**
- **现象**：`int()` 转换非数字字符串。
- **排查**：`int("abc")` 会报错。使用 `try/except ValueError` 捕获。先用 `str.isdigit()` 判断（注意负数/浮点字符串不适用）。`int(float(s))` 可转换 "3.14" 但会丢失精度。

**【PY-010】`UnicodeDecodeError: 'utf-8' codec can't decode byte`**
- **现象**：读取非 UTF-8 编码文件（如 GBK）时报错。
- **排查**：`open(file, encoding='gbk')` 指定正确编码。`chardet.detect()` 检测文件编码。`errors='ignore'` 跳过无法解码的字节（会丢失数据，谨慎使用）。

**【PY-011】`RecursionError: maximum recursion depth exceeded`**
- **现象**：递归调用层数过深。
- **排查**：检查递归函数是否有正确的终止条件。将递归改为迭代（用循环 + 栈）。若确实需要深层递归，`sys.setrecursionlimit(10000)` 提高限制（有栈溢出风险）。

**【PY-012】`MemoryError`**
- **现象**：内存不足，Python 无法分配对象。
- **排查**：检查是否一次性加载了超大文件（用逐行/分块读取代替 `f.read()`）。检查是否有无限增长的列表/字典/缓存。使用 `tracemalloc` 或 `memory_profiler` 定位内存分配大户[reference:53]。

**【PY-013】Python 进程内存持续增长（内存泄漏）**
- **现象**：长时间运行后内存占用不断上升，最终 OOM。
- **排查**：`tracemalloc` 在两个时间点 `take_snapshot()`，`compare_to()` 找出增长最多的代码行[reference:54]。检查全局缓存/列表是否无上限增长、循环引用（`gc.collect()` 后是否释放）、C 扩展泄漏。

**【PY-014】`RuntimeError: asyncio.run() cannot be called from a running event loop`**
- **现象**：在已有事件循环中调用 `asyncio.run()`。
- **排查**：Jupyter Notebook 中不能直接 `asyncio.run()`，使用 `await main()` 或 `nest_asyncio`。在异步函数内部，应 `await` 协程而非 `asyncio.run()`。

**【PY-015】`ConnectionError` / `requests.exceptions.ConnectionError`**
- **现象**：网络请求连接失败。
- **排查**：检查目标 URL 是否可达（`curl`/`ping`）。检查网络/代理/防火墙。`requests` 设置 `timeout` 避免无限等待。检查 DNS 解析是否正常。

**【PY-016】`requests.exceptions.Timeout`**
- **现象**：请求超时。
- **排查**：设置合理的 `timeout`（连接超时和读取超时分开）。检查目标服务响应时间。使用重试机制（`urllib3.Retry` 或手动循环）。高并发时注意限流。

**【PY-017】`SSLError: certificate verify failed`**
- **现象**：HTTPS 请求证书校验失败。
- **排查**：公司内网可能使用自签名证书，`verify=False` 可跳过校验（不安全，仅测试用）。或指定 CA 证书路径（`verify='/path/to/ca.pem'`）。`certifi` 包更新根证书。

**【PY-018】`json.decoder.JSONDecodeError`**
- **现象**：`json.loads()` 解析失败。
- **排查**：打印原始字符串确认是否为合法 JSON。检查是否有 BOM 头（`encoding='utf-8-sig'`）。检查是否空字符串或 HTML 错误页。`try/except` 捕获并记录原始内容。

**【PY-019】`UnicodeEncodeError: 'ascii' codec can't encode character`**
- **现象**：向文件/终端输出非 ASCII 字符（中文）时报错。
- **排查**：`open(file, 'w', encoding='utf-8')` 指定编码。设置环境变量 `PYTHONIOENCODING=utf-8`。检查 `sys.stdout.encoding`。

**【PY-020】`BrokenPipeError: [Errno 32] Broken pipe`**
- **现象**：管道写入时对端已关闭。
- **排查**：当 `| head` 等命令提前关闭管道时出现。在脚本中捕获 `BrokenPipeError` 并静默退出。`signal.signal(signal.SIGPIPE, signal.SIG_DFL)` 恢复默认行为。

**【PY-021】`pip install` 报 `Permission denied`**
- **现象**：全局安装包时权限不足。
- **排查**：不要用 `sudo pip`（会污染系统环境）。使用虚拟环境（`python -m venv venv`）安装。或 `pip install --user xxx` 安装到用户目录。修复目录权限而非滥用 sudo。

**【PY-022】`pip` 安装超时或速度极慢**
- **现象**：从 PyPI 下载包非常慢或超时。
- **排查**：使用国内镜像源：`pip install -i https://pypi.tuna.tsinghua.edu.cn/simple xxx`。在 `~/.pip/pip.conf` 或 `pip.ini` 中永久配置镜像源。检查网络代理设置。

**【PY-023】`venv` 创建虚拟环境后 `python` 仍指向系统版本**
- **现象**：激活虚拟环境后，`which python` 显示系统 Python 而非 venv 中的 Python。
- **排查**：确认激活命令正确（Linux: `source venv/bin/activate`；Windows: `venv\Scripts\activate`）。检查 Shell 配置中是否有别名覆盖。`deactivate` 后重新激活。

**【PY-024】多线程程序卡死（死锁）**
- **现象**：程序运行中挂起，无响应，CPU 占用低。
- **排查**：使用 `faulthandler`（`faulthandler.dump_traceback_later(30)`）打印卡死时的调用栈。检查多个 `Lock` 的获取顺序是否一致（避免交叉死锁）。使用 `threading.Lock` 的 `acquire(timeout=...)` 避免永久阻塞。

**【PY-025】`asyncio` 协程中调用了同步阻塞函数导致事件循环卡住**
- **现象**：异步程序中某个请求极慢，其他协程全部无法执行。
- **排查**：在 `async def` 中避免直接调用 `time.sleep()`、`requests.get()` 等同步阻塞函数。使用 `await asyncio.sleep()`、`httpx.AsyncClient`、`aiofiles`，或用 `await loop.run_in_executor()` 将阻塞调用放到线程池。

**【PY-026】`pytest` 运行时报 `ModuleNotFoundError`**
- **现象**：在 `tests/` 目录下运行 `pytest` 时找不到项目根目录的模块。
- **排查**：在项目根目录运行 `python -m pytest`。在 `tests/` 中添加 `conftest.py`，用 `sys.path.insert(0, '..')` 将上级目录加入路径。或将项目做成可安装包（`pip install -e .`），使用标准包结构。

**【PY-027】`pytest` 收集不到测试用例**
- **现象**：运行 `pytest` 显示收集到 0 个测试。
- **排查**：测试文件名必须以 `test_` 开头或 `_test.py` 结尾。测试函数必须以 `test_` 开头。测试类必须以 `Test` 开头且不能有 `__init__`。确认测试目录中没有 `__init__.py` 导致包结构混乱。

**【PY-028】`logging` 日志不输出或重复输出**
- **现象**：配置了 logger 但看不到日志，或日志重复打印多行。
- **排查**：检查 logger 的 `level` 是否高于日志级别。检查是否未添加 `Handler`。`logger.propagate = False` 防止向上级 logger 重复传递。`Handler` 被多次添加会导致重复输出。

**【PY-029】`subprocess` 调用外部命令卡死**
- **现象**：`subprocess.run()` 或 `Popen` 执行命令时挂起。
- **排查**：使用 `subprocess.run(cmd, capture_output=True, timeout=30)` 设置超时。若子进程输出大量数据且未读取，管道缓冲区满会导致死锁，使用 `communicate()` 读取。避免 `shell=True` 的注入风险。

**【PY-030】Python 脚本在 crontab 中运行失败**
- **现象**：手动运行正常，`crontab` 调度时失败。
- **排查**：Cron 环境变量极简，脚本中使用绝对路径。在 crontab 中显式设置 `PATH=/usr/local/bin:/usr/bin:/bin`。将 `stderr` 重定向到日志文件（`>> /tmp/cron.log 2>&1`）查看报错。虚拟环境使用绝对路径的 Python 解释器（`/path/to/venv/bin/python script.py`）。

十五、 苹果手机（iPhone）故障排查
【IPHONE-001】iPhone 完全黑屏，按电源键无任何反应

现象：屏幕全黑，按电源键、音量键均无响应，设备无振动或提示音。

排查：先连接原装充电器充电至少 30 分钟，排除电量耗尽。若仍黑屏，执行强制重启（iPhone 8 及更新机型：快速按一下音量加键松开→快速按一下音量减键松开→长按右侧侧边按钮，直到出现 Apple 标志后松手）。若强制重启无效，连接电脑进入恢复模式，在 Finder/iTunes 中选择“更新”尝试保留数据修复系统；若“更新”失败，再选择“恢复”（会清除数据）。

【IPHONE-002】开机卡在白苹果界面，反复重启无法进入系统

现象：开机后一直显示 Apple 标志，或白苹果与重启循环交替，无法进入锁屏界面。

排查：先执行强制重启。若无效，将 iPhone 连接电脑并进入恢复模式，优先选择“更新”（保留数据重装 iOS）。若“更新”失败或空间不足导致，选择“恢复”重装系统。若恢复模式也无法进入，尝试 DFU 模式刷机。

【IPHONE-003】屏幕触控局部失灵或完全无响应

现象：屏幕某些区域点击无反应，或整体触控失效，但显示正常。

排查：取下保护壳和钢化膜，用指尖（而非指甲）触摸屏幕。清洁屏幕表面油污和水分。执行强制重启。若仍无效，进入“设置→通用→传输或还原 iPhone→还原→还原所有设置”（不删数据，但会重置 Wi-Fi 密码等偏好设置）。还原后仍局部失灵，为触摸屏硬件故障，需检修。

【IPHONE-004】屏幕“鬼触”（自动乱跳、乱点）

现象：手指未触碰屏幕时，屏幕自动点击、滑动或打开应用。

排查：检查是否仅在充电时出现——非原装或非 MFi 认证充电器纹波干扰可导致鬼触，更换原装充电器测试。取下非原装钢化膜。执行强制重启。进入“设置→辅助功能→触控”，检查“触控调节”或“切换控制”是否被误开启并关闭。若硬件检测仍异常，触摸屏或排线故障。

【IPHONE-005】iPhone 无法充电，插线无反应

现象：连接充电线后，电池图标不显示充电状态，或充电断断续续。

排查：更换已知良好的原装或 MFi 认证充电线和电源适配器测试。检查充电口是否有棉絮、灰尘或氧化物，用干燥软毛刷（非金属）轻轻清理。若无线充电正常、仅有线充电失效，基本可锁定为尾插排线（充电接口模组）损坏，需更换。

【IPHONE-006】iPhone 充电极慢或电量不增反降

现象：插着充电器，电量长时间不增加，高负载使用时甚至下降。

排查：确认使用的是足够功率的充电器（建议 20W 及以上 PD 充电器）。检查充电线和接口是否损坏。在“设置→电池→电池健康与充电”中查看最大容量，低于 80% 时电池老化可能导致充电效率下降。若边充边玩高负载游戏，耗电速度可能超过充电速度，暂停使用后再观察。

【IPHONE-007】电池健康度低于 80%，续航明显缩短

现象：“电池健康与充电”中最大容量显示低于 80%，日常使用需频繁充电。

排查：最大容量低于 80% 意味着电池已显著老化，iOS 可能触发性能管理，且续航明显下降。建议前往 Apple 官方或授权服务商更换电池。更换前可开启“低电量模式”缓解，但无法逆转容量衰减。

【IPHONE-008】iPhone 待机耗电异常快

现象：夜间待机数小时掉电超过 10%—15%，或轻度使用下电量下降明显加快。

排查：进入“设置→电池”，查看过去 24 小时/10 天的耗电排行，重点关注“后台活动”占比高的应用，限制其后台刷新或卸载。关闭不必要的定位、蓝牙、热点和“常亮显示”（Pro 机型）。若待机耗电依然异常，且电池健康正常，可能是主板漏电，需检修。

【IPHONE-009】iPhone 频繁发热，甚至触发温度警告

现象：日常使用或充电时机身明显发烫，屏幕变暗、性能下降，严重时弹出“温度过高”警告并停止充电或关机。

排查：取下保护壳，将设备移至阴凉通风处（0—35℃环境）等待降温。关闭后台高耗电应用，暂停大型游戏/视频录制。检查“设置→电池”中的耗电排行，定位持续占用 CPU 的异常进程。若在常温环境下温度警告持续反复出现，则可能存在硬件故障，需检修。

【IPHONE-010】面容 ID 无法识别，提示“面容 ID 已停用”

现象：面容 ID 解锁失败，或设置中显示“检测到原深感摄像头出现问题，面容 ID 已停用”。

排查：清洁原深感摄像头区域（屏幕顶部刘海/灵动岛处），确保无贴膜遮挡、无污渍。执行强制重启。进入“设置→面容 ID 与密码”，输入锁屏密码后选择“重设面容 ID”并重新录入。若仍提示“已停用”，原深感摄像头硬件或排线故障，需 Apple 授权服务检修；此类问题软件无法修复。

【IPHONE-011】iPhone 无法连接 Wi-Fi

现象：Wi-Fi 开关可打开，但搜索不到网络，或输入密码后连接失败。

排查：确认“飞行模式”已关闭。在 Wi-Fi 设置中点击目标网络，选择“忘记此网络”后重新连接。重启路由器和 iPhone。卸载 VPN 或安全防护类软件后测试。若所有方法均无效，再执行“设置→通用→传输或还原 iPhone→还原→还原网络设置”（会清除已保存的 Wi-Fi 密码和蜂窝网络设置）。

【IPHONE-012】Wi-Fi 已连接但无法上网

现象：状态栏显示 Wi-Fi 图标，但浏览器、应用无法加载网络内容。

排查：用另一台设备连接同一 Wi-Fi 测试——若其他设备也无法上网，问题在路由器或宽带服务商，重启路由器和光猫，或联系 ISP。若仅 iPhone 异常，在 Wi-Fi 设置中“忘记此网络”后重连，还原网络设置，或检查是否开启了限制性 VPN/代理。

【IPHONE-013】蜂窝网络显示“无服务”或“正在搜索”

现象：状态栏显示“无服务”“正在搜索”或“SOS”，无法拨打电话或使用蜂窝数据。

排查：开关飞行模式（开启至少 15 秒后关闭）以强制重新注册网络。重启 iPhone。进入“设置→蜂窝网络”，确认蜂窝数据已开启、当前号码处于活跃状态。检查所在区域是否有运营商信号覆盖。若以上均正常仍无服务，可能是 SIM 卡或蜂窝硬件故障，换卡测试或联系运营商。

【IPHONE-014】通话时对方听不到自己的声音

现象：拨打电话或 FaceTime 时，对方反馈无声音或声音极小，自己可以听到对方。

排查：检查底部麦克风孔和背部摄像头附近的麦克风孔是否被保护壳、灰尘或异物堵塞，用软毛刷轻轻清理。打开“语音备忘录”录音并回放，判断麦克风是否正常工作。若录音正常但通话异常，检查通话应用权限或网络；若录音也无声音，麦克风硬件故障。

【IPHONE-015】扬声器外放无声或破音

现象：播放音乐、视频或铃声时，底部扬声器无声、声音极小或出现破音/杂音，耳机输出正常。

排查：确认“静音模式”已关闭（侧边静音开关拨离静音位）。进入“设置→声音与触感”，反复拖动“铃声和提醒”滑块，听扬声器是否有清晰提示音。用软毛刷清洁底部扬声器开孔。若清理后仍无声或破音，扬声器单元或排线硬件故障。

【IPHONE-016】相机黑屏或无法打开

现象：打开相机应用后屏幕全黑，或应用闪退，前后摄像头均无法使用。

排查：强制关闭相机应用后重新打开。执行强制重启。检查摄像头镜头是否有遮挡物或贴膜。若其他应用（如微信扫码、FaceTime）也无法调用相机，运行 iOS 诊断（关闭设备后按住侧边按钮启动“恢复助理”→诊断模式→移动设备资源检查器）测试相机硬件。诊断报错则摄像头模组或排线故障。

【IPHONE-017】相机对焦失败或画面模糊

现象：取景画面持续模糊，点击屏幕对焦无反应，或对焦后仍不清晰。

排查：清洁镜头表面（指纹和油污会导致模糊）。重启相机应用和 iPhone。检查是否使用了非原装镜头保护贴/膜，移除后测试。若仅特定焦距（如微距/长焦）异常，对应镜头模组或对焦马达故障。

【IPHONE-018】蓝牙无法连接或频繁断连

现象：蓝牙耳机/音箱在列表中可见但连接失败，或连接后频繁断开。

排查：在“设置→蓝牙”中点击目标设备右侧的“i”图标，选择“忽略此设备”，然后重新配对。确保蓝牙设备电量充足且处于配对模式。将 iPhone 与蓝牙设备靠近，远离 2.4GHz Wi-Fi 路由器（频段干扰）。更新 iOS 到最新版本。若仅特定蓝牙设备异常，该设备兼容性问题。

【IPHONE-019】iPhone 无法被电脑识别

现象：用数据线连接 iPhone 和电脑后，Finder/iTunes 无反应，或提示“无法识别设备”。

排查：更换已知良好的原装或 MFi 认证数据线，更换电脑 USB 接口（优先使用后置接口）。解锁 iPhone，在弹出“要信任此电脑吗？”时点击“信任”并输入锁屏密码。若仍无法识别，重启 iPhone 和电脑。无线充电正常而仅有线连接失效时，尾插排线故障可能性较高。

【IPHONE-020】iPhone 卡顿、掉帧、应用启动慢

现象：系统滑动不流畅，应用打开速度明显变慢，动画掉帧。

排查：检查存储空间，保持至少 10% 以上的可用空间。关闭不必要的“后台 App 刷新”。进入“设置→辅助功能→动态效果”，开启“减弱动态效果”可减轻 GPU 负担。重启 iPhone。若长期未更新系统，检查 iOS 更新。若电池健康低于 80%，性能管理可能限制峰值性能，更换电池可恢复。

【IPHONE-021】iPhone 频繁自动重启或意外关机

现象：使用中或待机时设备突然重启，或电量未耗尽却自动关机。

排查：检查电池健康度，老化电池在峰值负载下电压骤降可触发关机或重启，低于 80% 时优先更换电池。更新 iOS 到最新版本。检查是否有不兼容的应用或描述文件，尝试卸载近期安装的可疑应用。若电池健康正常且问题持续，可能是主板电源管理故障。

【IPHONE-022】iPhone 进水或受潮后异常

现象：设备接触液体后出现无法充电、扬声器杂音、屏幕水印或无法开机。

排查：立即关机，不要充电，不要按任何按键。用干燥的无绒布擦干表面，将设备放在通风干燥处自然风干，不要使用吹风机加热或插入大米。iPhone 虽有一定抗水能力，但进水属于液体损坏，不在标准保修范围内。干燥至少 24 小时后再尝试开机；若仍异常，需送修检测内部腐蚀情况。

【IPHONE-023】iPhone 存储空间已满，无法拍照或更新应用

现象：系统提示存储空间不足，相机无法保存照片，应用无法更新。

排查：进入“设置→通用→iPhone 存储空间”，查看各应用占用。优先清理大型应用缓存、旧聊天记录（微信/QQ 内清理）、重复照片和视频。卸载不常用的应用（保留数据卸载）。若系统数据占用异常大，可备份后恢复出厂设置。存储空间极度不足还可能导致白苹果或无法开机，需保持至少数 GB 空闲。

【IPHONE-024】更新 iOS 后卡顿、发热或耗电加快

现象：系统更新后短时间内设备变卡、发热增加、续航下降。

排查：大版本 iOS 更新后，系统会在后台重建索引、适配应用，通常持续 1—3 天，期间发热和耗电略高属于正常现象。保持设备连接 Wi-Fi 和充电器，让后台任务完成。若超过一周仍异常，检查是否有不兼容的应用更新，或备份后恢复出厂设置。若仅电池续航下降，检查电池健康度。

【IPHONE-025】iPhone 信号弱或通话断续

现象：蜂窝信号格数少，通话中出现断续、杂音或掉话。

排查：确认是否处于信号覆盖边缘（地下室、电梯、偏远区域），移动到开阔区域测试。取下金属材质保护壳（可能屏蔽天线）。开关飞行模式重新注册网络。检查运营商设置更新（设置→通用→关于本机，若有更新会弹出提示）。若同一地点其他手机信号正常，iPhone 蜂窝天线或基带可能存在故障。

【IPHONE-026】iPhone 屏幕出现绿线/粉线/白斑

现象：屏幕显示纵向或横向的绿色、粉色线条，或出现白色/彩色斑点，重启后不消失。

排查：截图后在另一台设备上查看该截图——若截图中没有线条/斑点，故障在屏幕硬件（排线或 OLED 面板）；若截图中有，则可能是软件/GPU 异常。硬件线条/斑点通常需更换屏幕总成。白斑在 OLED 屏幕上可能由局部老化或压伤导致，无法通过软件修复。

【IPHONE-027】iPhone 屏幕亮度异常（过暗、无法调节）

现象：屏幕亮度极低，或自动亮度调节失效，手动拖动亮度条无变化。

排查：检查“设置→辅助功能→显示与文字大小→自动亮度”是否开启。关闭“原彩显示”测试。确认设备是否因过热而自动降低亮度（降温后恢复即属正常保护机制）。若手动亮度条拖动完全无响应，环境光传感器或屏幕排线故障，需检修。

【IPHONE-028】iPhone 上的应用闪退

现象：打开某个应用后立即闪退，或使用中突然退出。

排查：强制关闭该应用后重新打开。检查 App Store 中该应用是否有更新。重启 iPhone。若仅特定应用闪退，卸载后重新安装。若多个应用同时闪退，检查 iOS 是否有可用更新，或“设置→通用→传输或还原 iPhone→还原→还原所有设置”。仍无效时，备份后恢复系统。

【IPHONE-029】iPhone 无法开机，充电时屏幕显示红色电池图标

现象：连接充电器后，屏幕显示空电池图标或红色电池图标，无法正常启动。

排查：这是电量极低的正常提示。保持连接原装充电器充电 至少 30 分钟至 1 小时，再尝试开机。若充电 1 小时后仍只显示红色电池且无法开机，可能电池深度亏电或充电电路故障。检查充电线和接口是否正常，必要时更换充电套装；仍无效则需检修电池或充电 IC。

【IPHONE-030】iPhone 通话时屏幕不熄灭（距离传感器失灵）

现象：拨打电话将手机贴近耳朵时，屏幕不自动熄灭，面部误触挂断或打开应用。

排查：清洁屏幕顶部听筒附近的距离传感器区域（刘海/灵动岛处），去除贴膜气泡、油污或保护壳遮挡。执行强制重启。若清洁和重启后仍不熄灭，距离传感器或前置排线故障，需检修。

【IPHONE-031】iPhone 无线充电失效或充电缓慢

现象：放在无线充电板上无充电反应，或充电速度极慢，有线充电正常。

排查：移除手机保护壳（尤其是厚重或含金属材质的壳）。确认无线充电板连接了足够功率的电源适配器，并将 iPhone 正面朝上、居中放置在充电板线圈位置。若使用 MagSafe，确认充电器为 Apple MagSafe 认证产品。若更换充电板和适配器后仍无法无线充电，而有线充电正常，可能是无线充电线圈或相关排线故障。

【IPHONE-032】iPhone 提示“检测到液体”无法充电

现象：连接充电线时，屏幕弹出“检测到液体”警告，充电被暂停。

排查：立即拔下充电线，不要尝试再次插入或甩动手机。将充电口朝下轻轻拍打，去除可能存在的液体，放在通风干燥处自然风干。不要使用吹风机、压缩空气或插入棉签/纸巾。等待至少 30 分钟至数小时后再尝试充电。若反复出现该提示且确认接口已完全干燥，充电口或线缆存在异常，需检修。
