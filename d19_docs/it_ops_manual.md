# 企业内部 IT 与运维排障知识库 (v1.0)

## 一、 电子餐牌 (DMB) 常见故障排查

1. **【DMB-001】电子餐牌屏幕不亮**
   - **现象**：单块或多块屏幕无显示。
   - **排查**：1. 检查 DMB 电源开关是否开启；2. 检查总闸断路器是否跳闸；3. 如果是单屏黑屏，尝试用遥控器对准黑屏按电源键（可能被误关）；4. 检查显示器背后的 DP 线或 HDMI 线是否松动。

2. **【DMB-002】显示白底 Logo**
   - **现象**：屏幕显示白底和品牌 Logo，无法显示菜单。
   - **排查**：多数由于 DMB 软件造成。长按 DMB 主机的电源键重启，若无法解决，检查网线是否插紧，如仍无法恢复，立刻报修市场 IT。

3. **【DMB-003】显示红底 Logo**
   - **现象**：屏幕显示红底 Logo。
   - **排查**：这是 DMB 主机信号未到达显示器。若两台显示器都出现，检查两台 DMB 主机是否有一台未开机；若一台显示，重新插拔对应主机的 DP 线。

4. **【DMB-004】画面停在一个界面或只有四分之一图片**
   - **现象**：画面卡死，或屏幕只显示部分画面。
   - **排查**：找到 DMB 显示器的遥控器，按下“TILE”键（拼接设置）重新设置屏幕阵列；若是画面卡死，重启 DMB 播放器。

5. **【DMB-005】菜单价格未更新**
   - **现象**：POS 端已修改价格，但餐牌未刷新。
   - **排查**：POS 端修改后通常需等待 15-20 分钟同步。若超时未更新，重启 POS 终端，并在 DMB 后台检查播放器是否处于“离线”状态。

6. **【DMB-006】“Page Load Error”（网页加载错误）**
   - **现象**：屏幕提示无法连接网络。
   - **排查**：用手机测试该网络能否正常上网。若网络正常，重启路由器和 DMB 播放器，等待 5 分钟重新建立连接。

7. **【DMB-007】显示系统初始化**
   - **现象**：开机后卡在“系统初始化”界面。
   - **排查**：重启 DMB 主机，并将 DMB 交换机上面的网线全部拔下重新插紧，等待 5-10 分钟。若未恢复，报修市场 IT。

8. **【DMB-008】播放器显示离线**
   - **现象**：DMB 后台监控显示门店播放器离线。
   - **排查**：查看后台最后一次连接时间，并请店员确认门店是否停电或断网；如果是夜间关屏导致，提示店员手动开机。

9. **【DMB-009】播放时有声音无画面**
   - **现象**：音频正常输出，但屏幕黑屏。
   - **排查**：检查 HDMI 线是否损坏（可更换线缆测试），检查显示器是否切换到了错误的输入源（如 DP 切到了 HDMI）。

10. **【DMB-010】画面出现条纹闪烁**
    - **现象**：屏幕上有横向或纵向的彩色条纹闪烁。
    - **排查**：通常是视频线接触不良或显卡故障。重新插拔视频线，若替换线缆后仍闪烁，需更换 DMB 主机。

11. **【DMB-011】DMB 交换机指示灯不亮**
    - **现象**：交换机上连接 DMB 主机的端口灯不亮。
    - **排查**：检查对应主机的网口灯是否亮起；更换一根网线测试；若仍不亮，更换交换机端口。

12. **【DMB-012】遥控器无法控制屏幕**
    - **现象**：按遥控器没反应。
    - **排查**：检查遥控器电池是否安装正确（正负极），或更换新电池；确认遥控器红外发射口是否被遮挡。

13. **【DMB-013】DMB 声音异常大或破音**
    - **现象**：音量调节失效，或者有杂音。
    - **排查**：检查主机后的音频线是否插紧，或者进入系统设置中重新调整音频输出格式（如从 PCM 改为自动）。

14. **【DMB-014】屏幕拼缝处图像错位**
    - **现象**：多屏拼接时，图像在边框处不连续。
    - **排查**：进入 DMB 播放软件的“屏幕拼接”设置，重新校准屏幕边框补偿参数。

15. **【DMB-015】主机开机后风扇狂转但无输出**
    - **现象**：DMB 主机内部风扇高速旋转，但显示器黑屏。
    - **排查**：主板或显卡故障的典型表现，需断电并报修更换主机。

16. **【DMB-016】定时开关机失效**
    - **现象**：到点不自动关机或开机。
    - **排查**：检查 BIOS 中的 RTC（实时时钟）唤醒功能是否开启，系统时间是否准确。

17. **【DMB-017】特定菜品图片无法显示**
    - **现象**：菜单上其他菜品正常，就某个菜品显示为“裂图”。
    - **排查**：检查该图片的格式（建议 JPG/PNG），或在后台重新上传该图片资源。

18. **【DMB-018】开机提示“无信号输入”**
    - **现象**：显示器弹出“No Signal”。
    - **排查**：检查显示器信号源是否选对；拔下视频线重新插入；检查主机是否死机。

19. **【DMB-019】DMB 主机频繁重启**
    - **现象**：每隔几分钟 DMB 主机就自动重启。
    - **排查**：检查电源线是否松动导致接触不良；检查主机散热是否良好（风扇是否被灰尘卡死）；系统中毒或崩溃也会导致重启。

20. **【DMB-020】DMB 无法连接后台管理系统**
    - **现象**：后台无法下发新菜单。
    - **排查**：检查门店网络能否访问外部网络；检查 DMB 播放器绑定的 IP 地址是否与当前局域网冲突。

## 二、 华硕 (ASUS) 笔记本及外设故障排查

21. **【ASUS-001】开机没反应/屏幕黑屏但电源灯亮**
    - **现象**：电源指示灯亮，但屏幕黑屏。
    - **排查**：长按电源键 15 秒强制重置 EC（嵌入式控制器），松开后再按一次开机。这是华硕官方推荐的假死恢复方法。

22. **【ASUS-002】键盘部分按键无响应**
    - **现象**：敲击某些键无法输入。
    - **排查**：外接 USB 键盘测试，若外接键盘正常，则是内置键盘排线松动或键盘硬件损坏，需拆机重新插拔排线。

23. **【ASUS-003】触摸板失灵**
    - **现象**：触摸板无法移动光标。
    - **排查**：按 `Fn + F9` 或 `F10` 检查是否误触了触摸板锁定键；进入“设备管理器”检查驱动是否正常，或重新安装触摸板驱动。

24. **【ASUS-004】电池无法充电或充不满**
    - **现象**：插着电源，但电量不增加，或卡在 80%。
    - **排查**：华硕 MyASUS 软件可能开启了“电池健康充电”（限制充至 80%），可在软件中关闭；确认是否使用了原装 65W/100W USB-C 充电器。

25. **【ASUS-005】开机提示“找不到启动设备” (Boot Device Not Found)**
    - **现象**：开机直接进入 BIOS 或报错。
    - **排查**：进入 BIOS 查看硬盘是否被识别（Main 或 Boot 菜单下）；若未识别，可能是硬盘松动或 SSD 损坏；若识别了，检查启动顺序（Boot Option Priorities）是否把 Windows Boot Manager 设为第一。

26. **【ASUS-006】电脑严重发热且风扇噪音大**
    - **现象**：用一会就烫手，风扇狂转。
    - **排查**：使用 MyASUS 测试风扇；检查任务管理器是否有后台进程占用高 CPU；若长期未清理，需拆机清理出风口灰尘并更换导热硅脂。

27. **【ASUS-007】键盘背光不亮**
    - **现象**：晚上打字看不见键盘。
    - **排查**：按 `Fn + F7`（或对应带灯光图标的 F 键）开启背光；在 MyASUS 中检查是否禁用了键盘背光。

28. **【ASUS-008】Wi-Fi 频繁断开**
    - **现象**：无线网络连接不稳定，经常掉线。
    - **排查**：在设备管理器中取消勾选网卡“允许计算机关闭此设备以节约电源”；更新无线网卡驱动；路由器信道干扰也可能导致。

29. **【ASUS-009】外接显示器无法识别**
    - **现象**：通过 HDMI/Type-C 接显示器，无信号。
    - **排查**：按 `Win + P` 切换投影模式（复制/扩展）；更换线缆或接口测试；检查显卡驱动是否正常。

30. **【ASUS-010】系统蓝屏 (BSOD)**
    - **现象**：不定时蓝屏重启。
    - **排查**：使用 MyASUS 的硬件诊断；如果是更新后出现，卸载最近补丁或驱动；内存条接触不良也会导致蓝屏。

31. **【ASUS-011】摄像头无法打开**
    - **现象**：提示“未找到摄像头”。
    - **排查**：检查键盘上的摄像头物理防窥拨片是否关闭；按 `Fn + F10`（或带摄像头图标的键）开启；检查隐私设置中是否允许应用使用摄像头。

32. **【ASUS-012】开机进入 BIOS 后无法退出**
    - **现象**：开机直接停在 BIOS 界面。
    - **排查**：按 `F10` 保存并退出；若仍循环进入 BIOS，可能是找不到硬盘或键盘 F2 键卡死。

33. **【ASUS-013】USB 接口不识别设备**
    - **现象**：插入 U 盘没反应。
    - **排查**：更换其他 USB 接口（Type-A 换 Type-C）；在设备管理器卸载 USB 控制器驱动后重启让系统重装。

34. **【ASUS-014】屏幕闪烁或花屏**
    - **现象**：屏幕出现雪花点或线条。
    - **排查**：外接显示器测试，若外接正常则是笔记本屏幕排线或液晶面板故障；若外接也花屏则是显卡故障。

35. **【ASUS-015】声音外放破音或无声**
    - **现象**：扬声器没声音，插耳机有声音。
    - **排查**：检查声卡驱动（Realtek 或 DTS）；在 MyASUS 中做音频诊断；可能是扬声器排线脱落。

36. **【ASUS-016】开机提示 CMOS Date/Time Not Set**
    - **现象**：每次开机时间都回到默认。
    - **排查**：主板上的纽扣电池没电了，需拆机更换 CR2032 纽扣电池。

37. **【ASUS-017】Fn 快捷键失效**
    - **现象**：按 Fn 调亮度/音量没反应。
    - **排查**：安装华硕 ATK Package（快捷键驱动）或 MyASUS 系统控制驱动。

38. **【ASUS-018】电脑自动休眠或关机**
    - **现象**：用着用着突然黑屏关机。
    - **排查**：温度过高触发过温保护；电源适配器功率不足（非原装）导致供电中断；内存或主板虚焊。

39. **【ASUS-019】键盘输入乱码或错乱**
    - **现象**：按 A 出 B。
    - **排查**：检查输入法是否设置混乱；外接键盘测试，若外接正常则是内置键盘电路短路，需更换键盘。

40. **【ASUS-020】笔记本无法开机，充电指示灯闪烁**
    - **现象**：指示灯闪烁，按开机键没反应。
    - **排查**：断开电源，长按电源键 40 秒释放静电；重新插上电源适配器再试；如果闪红灯，可能是主板或电源故障。

## 三、 三星 (Samsung) 电视及显示设备故障排查

41. **【TV-001】电视黑屏但有声音**
    - **现象**：能看到菜单或背光亮，但没图像，声音正常。
    - **排查**：检查信号源设备（机顶盒/电脑）是否开机；更换 HDMI 线；进入图像设置重置画面；背光模组或 T-CON 板故障会导致无图像有声音。

42. **【TV-002】换台时短暂黑屏 2-3 秒**
    - **现象**：切换频道或输入源时，黑屏几秒钟后恢复。
    - **排查**：这是数字电视信号解码和 HDR 元数据重载的正常现象，无需维修。

43. **【TV-003】电视屏幕闪烁或雪花**
    - **现象**：画面有雪花点或间歇性闪烁。
    - **排查**：检查天线信号强度（进入自诊断查看信号强度是否在 65% 以上）；HDMI 接口松动或氧化；受潮导致电路阻抗变化。

44. **【TV-004】电视无声音，但图像正常**
    - **现象**：画面正常，完全没有声音。
    - **排查**：检查音量是否静音；检查“音效输出”设置是否被误改为“蓝牙”或“外部音响”；进入“自诊断 -> 声音测试”判断是扬声器还是主板故障。

45. **【TV-005】电视开机后自动关机**
    - **现象**：开机几秒或几分钟后自动断电。
    - **排查**：电源板电容老化或主板保护机制触发；检查遥控器是否有按键卡住；拔掉电源静置 3 分钟硬重启。

46. **【TV-006】电视无法连接 Wi-Fi**
    - **现象**：搜索不到无线网络或连接失败。
    - **排查**：确认路由器开启了 2.4G 频段（部分老电视不支持 5G）；在“网络”设置中重新输入密码；重启电视和路由器。

47. **【TV-007】电视应用商店无法打开**
    - **现象**：点进去一直转圈。
    - **排查**：检查 DNS 设置（改为 114.114.114.114 或 8.8.8.8）；电视系统时间是否正确（时间错误会导致证书验证失败）；系统版本过低。

48. **【TV-008】遥控器失灵**
    - **现象**：按键没反应，指示灯不亮。
    - **排查**：更换电池（注意正负极）；如果是蓝牙遥控器，需按住“返回”和“播放暂停”键重新配对；清理遥控器发射窗。

49. **【TV-009】电视屏幕出现竖线或横线**
    - **现象**：屏幕上有一条或多条彩色/黑色线条。
    - **排查**：屏幕面板 (Panel) 故障或排线（COF）损坏，通常需要更换整个屏幕总成，成本极高，建议直接报修售后。

50. **【TV-010】电视无法识别 U 盘**
    - **现象**：插上 U 盘，电视没反应。
    - **排查**：U 盘格式必须为 FAT32 或 NTFS；U 盘容量过大（如超过 1TB）可能不支持；部分三星电视需要在“源”菜单里手动选择 USB。

51. **【TV-011】电视画面颜色失真（偏红/偏蓝）**
    - **现象**：颜色异常。
    - **排查**：检查 HDMI 线；如果是有线电视，检查三色 AV 线是否插错；进入图像设置恢复出厂默认。

52. **【TV-012】电视开机画面卡在 Logo 处**
    - **现象**：一直显示 Samsung Logo。
    - **排查**：系统固件损坏，需要去官网下载对应型号的固件到 U 盘进行强制刷机（升级）。

53. **【TV-013】电视声音和画面不同步**
    - **现象**：口型对不上声音。
    - **排查**：进入“声音 -> 音效 -> 音频延迟”菜单，调整延迟数值（通常在 0-100ms 之间）；外接机顶盒的问题请检查机顶盒设置。

54. **【TV-014】电视右下角出现“无信号”提示**
    - **现象**：提示没有信号源。
    - **排查**：检查机顶盒是否开机；用电视遥控器按“信号源”键，切换到正确的 HDMI 接口（如 HDMI 1）。

55. **【TV-015】电视屏幕漏光**
    - **现象**：在暗色背景下，四角或边缘有白光。
    - **排查**：液晶面板组装公差导致，轻微漏光属于正常现象，若严重漏光影响观看，在保修期内申请换机。

56. **【TV-016】电视无法投屏**
    - **现象**：手机搜索不到电视，或投屏失败。
    - **排查**：确保手机和电视连接同一个 Wi-Fi；打开电视的“多屏互动”或“AirPlay”功能；部分视频 App 因版权限制禁止投屏。

57. **【TV-017】电视背光闪烁后黑屏**
    - **现象**：开机瞬间背光亮一下然后黑屏，声音正常。
    - **排查**：这是典型的背光灯条损坏或背光驱动板故障，需要更换灯条或驱动板。

58. **【TV-018】无法通过 HDMI 识别电脑**
    - **现象**：电脑接上电视没反应。
    - **排查**：电脑上按 `Win + P` 选择复制或扩展；检查 HDMI 线是否过长（劣质长线信号衰减严重）；电视接口是否损坏。

59. **【TV-019】电视待机指示灯不亮**
    - **现象**：彻底不通电。
    - **排查**：检查电源插座是否有电；电视电源线是否松动；内部电源板保险丝烧毁。

60. **【TV-020】蓝牙音响/耳机无法连接电视**
    - **现象**：搜不到设备。
    - **排查**：进入“声音 -> 音效输出 -> 蓝牙设备列表”进行配对；部分老款三星电视不支持蓝牙音频输出。

## 四、 海康威视 (Hikvision) 监控系统故障排查

61. **【HIK-001】录像机提示“无网络视频”或画面黑屏**
    - **现象**：NVR 上某个通道无法显示画面。
    - **排查**：检查摄像机是否通电（看红外灯是否亮）；检查网线连接和交换机指示灯；查看 NVR 的“IP 通道”报错，如果是“网络不可达”，检查 IP 地址是否冲突。

62. **【HIK-002】萤石云不在线，手机无法远程观看**
    - **现象**：手机 App 显示设备离线。
    - **排查**：确认录像机是否支持萤石云并已启用；检查录像机的网络能否自动获取 IPv4 地址；尝试切换网络环境（如换一个路由器）测试。

63. **【HIK-003】回放时搜不到录像文件**
    - **现象**：时间轴上没有录像。
    - **排查**：检查“录像计划”是否配置为全天定时录像；检查硬盘状态是否正常（可做 S.M.A.R.T 检测）；检查设备系统时间是否正确，时间错误会导致录像检索不到。

64. **【HIK-004】录像机无法识别硬盘**
    - **现象**：提示“硬盘不存在”或“异常”。
    - **排查**：检查硬盘数据线和电源线是否插紧；进入“硬盘管理”尝试格式化硬盘；若格式化失败，硬盘可能已损坏。

65. **【HIK-005】摄像机频繁掉线**
    - **现象**：画面时有时无，IP 通道频繁断开。
    - **排查**：检查网线水晶头是否氧化（重做水晶头）；PoE 交换机供电不足（检查总功率）；IP 地址冲突；摄像机固件 Bug。

66. **【HIK-006】监控画面白天正常，晚上黑屏**
    - **现象**：白天有图像，晚上就黑屏。
    - **排查**：摄像机电源功率不够，夜间红外灯开启导致供电不足；或者光敏传感器故障导致红外灯不切换。

67. **【HIK-007】监控画面偏色（偏红/偏绿）**
    - **现象**：颜色异常。
    - **排查**：摄像机红外切换滤光片（ICR）卡住，需要拆机拨动或更换；或者受到强光照射导致传感器受损。

68. **【HIK-008】局域网内电脑无法访问录像机**
    - **现象**：电脑浏览器或客户端连不上 NVR。
    - **排查**：检查电脑 IP 是否与录像机在同一网段；SADP 软件能否搜到设备；Windows 防火墙是否拦截了 8000 端口。

69. **【HIK-009】监控画面出现水波纹或横条干扰**
    - **现象**：画面有干扰纹。
    - **排查**：视频线缆（如果是模拟系统）与强电线路距离过近；网络传输系统的接地不良；摄像机电源不纯净。

70. **【HIK-010】NVR 无法添加第三方摄像机（如大华）**
    - **现象**：添加时提示“未知错误”或“参数错误”。
    - **排查**：确认是否支持 ONVIF 协议；第三方摄像机的 ONVIF 用户和密码是否已创建并输入正确；修改主码流为 H.264 格式。

71. **【HIK-011】监控主机报警“硬盘满”**
    - **现象**：一直滴滴响，提示硬盘满。
    - **排查**：进入“录像配置”开启“循环覆盖”功能（老录像会被新录像覆盖）；如果开启了循环覆盖仍报满，可能是硬盘逻辑坏道。

72. **【HIK-012】云台摄像机无法转动**
    - **现象**：控制云台没反应。
    - **排查**：检查云台电源；检查 NVR 的 RS485 线（A/B 线）是否接反；检查云台的协议和波特率设置是否与 NVR 一致。

73. **【HIK-013】监控画面时间不对**
    - **现象**：OSD 时间与现实时间不符。
    - **排查**：在 NVR 系统设置中“手动校时”或开启“NTP 自动校时”。

74. **【HIK-014】客户端预览有画面，网页预览没画面**
    - **现象**：只能通过特定软件看。
    - **排查**：浏览器不兼容（建议使用 IE 或 Edge 的 IE 模式）；未安装 Web 控件插件；端口未映射（远程时）。

75. **【HIK-015】摄像机画面模糊不清**
    - **现象**：焦点虚。
    - **排查**：摄像机镜头有灰尘或保护膜未撕；手动调焦镜头的后焦没调好；镜头起雾。

76. **【HIK-016】移动侦测报警不触发**
    - **现象**：有人走过，但不录像也不报警。
    - **排查**：检查是否已开启“移动侦测”并绘制了侦测区域；检查“联动方式”是否勾选了录像或上传中心；灵敏度是否过低。

77. **【HIK-017】声音异常（有杂音或无声）**
    - **现象**：带拾音器的摄像头声音不清楚。
    - **排查**：检查音频线是否接在正确的 Audio In 接口上；编码格式是否兼容；如果是网络摄像机，是否开启了音频流。

78. **【HIK-018】录像下载下来无法播放**
    - **现象**：用播放器打开是黑屏。
    - **排查**：海康录像通常是专用格式，需使用海康官网下载的 VSPlayer 播放器；或检查录像文件是否下载完整。

79. **【HIK-019】监控画面卡顿严重**
    - **现象**：一顿一顿的。
    - **排查**：网络带宽不足（降低码率或子码流预览）；交换机带宽被占满；硬盘有坏道导致写入卡顿。

80. **【HIK-020】设备被锁定**
    - **现象**：登录提示“用户被锁定”。
    - **排查**：多次输错密码触发安全保护。可以通过 SADP 软件导出 XML 文件发给海康售后重置；或等待 30 分钟后自动解锁。

## 五、 IT技术支持 / 桌面运维常见故障排查

81. **【DESK-001】电脑无法开机（指示灯不亮）**
    - **现象**：按开机键没反应。
    - **排查**：检查电源线是否插紧；检查插排是否通电；如果是笔记本，检查电源适配器是否损坏；台式机可尝试短接主板 PWR 针脚测试。

82. **【DESK-002】开机主机运转但屏幕无显示**
    - **现象**：风扇转，但显示器黑屏。
    - **排查**：检查显示器电源和信号线；拔下内存条用橡皮擦拭金手指后重新插上；如果有独立显卡，检查显卡是否松动。

83. **【DESK-003】网络打印机显示“脱机”**
    - **现象**：无法打印，状态为脱机。
    - **排查**：在“设备和打印机”中取消勾选“脱机使用打印机”；检查打印机网络是否连通（ping 打印机 IP）；重启打印服务 (Print Spooler)。

84. **【DESK-004】打印机卡纸**
    - **现象**：无法进纸或出纸。
    - **排查**：关闭电源，打开后盖或侧盖，顺着出纸方向缓慢拉出纸张；检查是否有碎纸屑残留；检查搓纸轮是否老化。

85. **【DESK-005】电脑无法连接网络（网络图标打叉）**
    - **现象**：有线或无线网络均无法连接。
    - **排查**：检查网线是否插好（看网口灯是否亮）；禁用再启用网卡；检查交换机端口或路由器是否死机；使用 `ipconfig /release` 和 `ipconfig /renew` 重新获取 IP。

86. **【DESK-006】网络图标有感叹号（受限访问）**
    - **现象**：连上了 Wi-Fi 或网线，但上不了网。
    - **排查**：可能是 IP 冲突或 DHCP 没获取到地址，使用 `ipconfig` 查看是否为 169.254.x.x；手动设置正确的 DNS 地址；重启路由器。

87. **【DESK-007】系统蓝屏 (BSOD)**
    - **现象**：Windows 崩溃，出现蓝色笑脸或代码。
    - **排查**：记录蓝屏错误代码（如 IRQL_NOT_LESS_OR_EQUAL）；如果是新装驱动后出现，进入安全模式卸载；运行内存诊断工具 (mdsched.exe)。

88. **【DESK-008】开机提示“Bootmgr is missing”**
    - **现象**：无法引导系统。
    - **排查**：BIOS 启动顺序错误（首选不是系统盘）；系统引导文件损坏，需使用 PE U 盘修复引导区。

89. **【DESK-009】电脑系统非常卡顿**
    - **现象**：反应慢，风扇响。
    - **排查**：打开任务管理器查看 CPU/内存/磁盘占用率；检查是否中了挖矿病毒；如果是机械硬盘，建议更换为固态硬盘 (SSD)；增加内存条。

90. **【DESK-010】无法访问共享文件夹**
    - **现象**：输入 `\\IP` 提示无权限或找不到网络路径。
    - **排查**：检查网络发现和文件共享是否开启；检查目标电脑的防火墙是否放行了 SMB 端口；检查输入的用户名和密码是否正确；检查目标电脑的共享权限设置。

91. **【DESK-011】鼠标或键盘失灵**
    - **现象**：动不了，打不了字。
    - **排查**：更换 USB 接口；如果是无线键鼠，更换电池或重新对码；在设备管理器卸载驱动后重启。

92. **【DESK-012】显示器闪烁或出现水波纹**
    - **现象**：屏幕闪。
    - **排查**：检查 VGA/HDMI 线是否插紧；如果是 VGA 线，检查针脚是否弯曲；附近有强磁场（如大功率音箱）干扰；刷新率设置不匹配。

93. **【DESK-013】C盘空间不足**
    - **现象**：飘红，提示空间不足。
    - **排查**：清理 Windows 临时文件 (temp)、更新缓存；卸载不用的软件；将虚拟内存转移到其他盘；使用清理软件（如 Dism++）清理 WinSxS 文件夹。

94. **【DESK-014】无法安装软件（权限不足）**
    - **现象**：点击安装包没反应或报错。
    - **排查**：当前用户不是管理员，右键选择“以管理员身份运行”；组策略限制了安装，需联系 IT 部门放权。

95. **【DESK-015】弹出“此设备已被管理员禁用”**
    - **现象**：如 U 盘无法读取。
    - **排查**：IT 部门通过域控或注册表禁用了 USB 存储设备；需提交工单申请临时解禁。

96. **【DESK-016】系统时间不准确**
    - **现象**：开机后时间重置，或者时间跑偏。
    - **排查**：主板纽扣电池没电（更换 CR2032）；在“Internet 时间”设置中同步 `ntp.aliyun.com` 或 `time.windows.com`。

97. **【DESK-017】开机自启软件太多**
    - **现象**：开机要等很久。
    - **排查**：任务管理器 -> 启动项，禁用不必要的软件（如各类全家桶）；使用火绒等安全软件的启动项管理功能。

98. **【DESK-018】Office 提示激活失败**
    - **现象**：Word/Excel 无法编辑，提示产品未激活。
    - **排查**：检查是否为公司购买的批量授权版；检查公司 KMS 服务器是否可达；可能是账号登录状态过期，需重新登录公司账号。

99. **【DESK-019】网页打不开但 QQ/微信能用**
    - **现象**：浏览器无法浏览网页。
    - **排查**：DNS 解析问题，检查网卡的 DNS 设置（改为 114.114.114.114 或 8.8.8.8）；浏览器设置了代理，在设置中关闭代理；清除浏览器缓存。

100. **【DESK-020】耳机插入前面板没声音**
     - **现象**：主机前面板耳机孔无声，后面板正常。
     - **排查**：Realtek 音频管理器设置中，勾选“禁用前面板插孔检测”；前面板音频线未插在主板正确的 AAudio 跳线针脚上。

## 六、 网络工程师常见故障排查

101. **【NET-001】局域网内同一 VLAN 下两台电脑互相 ping 不通**
     - **现象**：同网段不通。
     - **排查**：检查网线、端口状态（`display interface brief`）；检查交换机端口是否划分到正确 VLAN；检查是否有 STP 环路导致端口阻塞；检查 ARP 表是否有对应的 MAC。

102. **【NET-002】同一 VLAN 通，跨 VLAN 无法 ping 通**
     - **现象**：跨网段不通。
     - **排查**：检查三层交换机或路由器的 VLANIF 接口是否配置了 IP 地址并 `undo shutdown`；检查路由表是否有目标网段的路由；检查 ACL 或防火墙是否拦截。

103. **【NET-003】网络突然极度卡顿，交换机指示灯狂闪**
     - **现象**：广播风暴。
     - **排查**：典型二层环路。查看交换机 CPU 利用率；使用 `display interface` 查看端口广播包数量是否暴增；开启 STP/RSTP 并检查端口角色，找出环路端口并 `shutdown`。

104. **【NET-004】能 ping 通网关，但无法访问外网**
     - **现象**：内网通，外网断。
     - **排查**：检查核心路由器的默认路由是否正确指向运营商网关；检查 NAT 配置是否生效（`display nat session`）；检查 DNS 是否能解析外网域名。

105. **【NET-005】Trunk 链路不通，跨交换机 VLAN 通信失败**
     - **现象**：多台交换机级联后，不同交换机的同 VLAN 用户不通。
     - **排查**：检查 Trunk 端口是否允许对应的 VLAN 通过（`port trunk allow-pass vlan`）；两端的封装协议（802.1Q）是否一致；Native VLAN 是否匹配。

106. **【NET-006】IP 地址冲突**
     - **现象**：网络时断时续，提示 IP 冲突。
     - **排查**：在核心交换机上使用 `display arp | include 冲突IP` 找到 MAC；通过 `display mac-address` 查找该 MAC 连接在哪个端口；找到私自接路由器的用户并关闭其 DHCP 服务。

107. **【NET-007】交换机端口频繁 Up/Down**
     - **现象**：网络频繁闪断。
     - **排查**：检查网线质量和水晶头是否氧化；光模块故障或光纤头脏污（使用酒精擦拭）；双工模式不匹配（强制全双工 vs 自协商）；端口协商速率不匹配。

108. **【NET-008】DHCP 客户端获取不到 IP 地址**
     - **现象**：电脑获取到 169.254.x.x。
     - **排查**：检查 DHCP 服务器地址池是否耗尽；检查交换机上的 DHCP Relay（中继）配置是否正确；检查 VLAN 接口下是否绑定了错误的 DHCP 服务器组。

109. **【NET-009】OSPF 邻居建立不起来**
     - **现象**：路由器之间无法建立邻居关系。
     - **排查**：检查 Router ID 是否冲突；检查 Hello 和 Dead 定时器是否一致；检查区域 ID (Area ID) 是否相同；检查 MTU 是否匹配；检查认证密码是否一致。

110. **【NET-010】网络丢包严重**
     - **现象**：ping 丢包。
     - **排查**：检查端口是否有 CRC 错误（`display interface`）；检查链路带宽是否被占满（使用 `display interface | include rate` 查看流量）；光模块功率是否过低。

111. **【NET-011】交换机无法 Telnet/SSH 登录**
     - **现象**：远程管理失败。
     - **排查**：检查 VTY 线路配置（`user-interface vty`）；检查是否配置了 `authentication-mode` 和对应的用户名密码；检查 ACL 是否限制了源 IP 访问。

112. **【NET-012】MAC 地址漂移**
     - **现象**：交换机日志报警 MAC 地址漂移。
     - **排查**：通常是由于网络中存在环路，或者两台交换机互联的链路捆绑（Eth-Trunk）配置错误；也有可能是 ARP 欺骗病毒导致。

113. **【NET-013】光纤链路不通**
     - **现象**：光口指示灯不亮。
     - **排查**：检查光纤收发端是否接反（TX 接 RX）；使用光功率计测试发光功率和接收灵敏度是否正常；清洁光纤端面。

114. **【NET-014】VLAN 间通信被 ACL 阻断**
     - **现象**：配置了 ACL 后，部分网段无法互访。
     - **排查**：检查 ACL 规则的匹配顺序（自上而下匹配）；检查是否放行了回程流量；检查 ACL 应用的方向（inbound / outbound）是否正确。

115. **【NET-015】无线网络信号弱，连接不稳定**
     - **现象**：Wi-Fi 掉线。
     - **排查**：检查 AP 功率设置；检查信道干扰（使用 Wi-Fi 分析仪，将 2.4G 信道固定在 1/6/11）；检查终端是否在 AP 覆盖边缘；AP 接入用户数是否超限。

116. **【NET-016】无线终端无法获取 IP 地址**
     - **现象**：连上 Wi-Fi 但上不了网。
     - **排查**：检查无线控制器的 DHCP 中继配置；检查 AP 的管理 VLAN 和业务 VLAN 是否配置正确；检查是否开启了 MAC 地址认证。

117. **【NET-017】端口安全 (Port-Security) 导致断网**
     - **现象**：用户换了一台电脑，插上网线没网。
     - **排查**：交换机端口配置了 `port-security` 绑定了原来的 MAC 地址，新电脑的 MAC 不匹配导致端口 err-disabled。需进入接口 `shutdown` 再 `undo shutdown`，或清除 MAC 绑定。

118. **【NET-018】路由环路**
     - **现象**：数据包在路由器之间无限循环，TTL 超时。
     - **排查**：检查静态路由的下一跳是否指向了自己；检查动态路由协议（如 RIP）的防环机制是否开启；检查路由汇总是否产生了环路。

119. **【NET-019】VPN 连接成功但无法访问内部服务器**
     - **现象**：拨上 VPN 后，能 ping 通 VPN 网关，但访问不了内网服务器。
     - **排查**：检查 VPN 客户端的路由表，是否缺少目标内网网段的路由；检查防火墙 VPN 策略是否放行了到内网服务器的流量；检查服务器自身的防火墙是否拦截了 VPN 地址池。

120. **【NET-020】网络设备 CPU 占用率极高**
     - **现象**：交换机/路由器管理界面卡顿，业务转发受影响。
     - **排查**：是否有广播风暴；是否有针对设备的攻击（如 ARP 攻击）；开启了大量的 Debug 调试信息；查看 `display cpu-usage` 定位是哪个进程占用高。

## 七、 运维工程师常见故障排查

121. **【OPS-001】服务器 CPU 使用率 100%**
     - **现象**：CPU 跑满，业务响应慢。
     - **排查**：使用 `top` 找到占用最高的进程 PID；使用 `top -H -p <PID>` 查看是哪个线程占用高；使用 `jstack <PID> > stack.log`（Java 应用）排查代码死循环；检查是否有异常定时任务或挖矿病毒。

122. **【OPS-002】服务器内存耗尽 (OOM)**
     - **现象**：内存耗尽，系统触发 OOM Killer 杀死进程。
     - **排查**：使用 `free -h` 查看内存，`ps aux --sort=-%mem | head` 找出内存大户；使用 `vmstat 1` 观察；检查应用是否存在内存泄漏，查看 `/var/log/messages` 是否有 OOM 记录。

123. **【OPS-003】磁盘空间已满 (No space left on device)**
     - **现象**：无法写入日志或数据。
     - **排查**：`df -h` 查看已满的分区；`du -sh /* | sort -nr` 层层排查大文件夹；`lsof +L1` 查找被删除但未释放空间的文件；`df -i` 查看 inode 是否耗尽。

124. **【OPS-004】磁盘 I/O 负载极高 (IO Wait 高)**
     - **现象**：系统卡顿，`top` 中的 `wa` 值很高。
     - **排查**：使用 `iostat -x 1` 查看哪个磁盘 (`%util`) 被占满；`iotop` 查看是哪个进程在进行大量读写；检查是否有大型日志轮转或数据库备份任务在跑；磁盘是否有坏道。

125. **【OPS-005】系统负载 (Load Average) 很高，但 CPU 空闲**
     - **现象**：`uptime` 显示负载很高。
     - **排查**：通常是因为大量进程在等待 I/O（磁盘读写或网络）。检查是否有进程卡在 `D` 状态（不可中断睡眠）；检查 NFS 挂载是否掉线。

126. **【OPS-006】Nginx 报 502 Bad Gateway**
     - **现象**：访问网站报错 502。
     - **排查**：Nginx 连不上后端服务。检查后端服务（如 Tomcat、PHP-FPM）是否存活；检查 Nginx 的 `proxy_pass` 地址和端口是否正确；检查后端服务是否因超时或 worker 进程满而拒绝连接；检查 Nginx 的 `error.log`。

127. **【OPS-007】Nginx 报 504 Gateway Timeout**
     - **现象**：页面一直转圈，最后报 504。
     - **排查**：后端服务处理超时。检查后端程序是否卡死；检查 Nginx 配置中的 `proxy_read_timeout` 和 `proxy_connect_timeout` 是否设置过短；检查网络延迟。

128. **【OPS-008】MySQL 连接数满了 (Too many connections)**
     - **现象**：应用连不上数据库。
     - **排查**：登录 MySQL（可能需要 `--max-connections=200` 临时登录），执行 `show processlist` 查看卡住的查询；杀掉 (kill) 睡眠时间过长的连接；加大 `max_connections` 参数；检查应用连接池是否未正确释放。

129. **【OPS-009】Redis 响应变慢或超时**
     - **现象**：接口响应慢，依赖 Redis。
     - **排查**：使用 `redis-cli --latency` 测试延迟；执行 `info` 查看是否内存碎片率过高；是否存在大 key（使用 `redis-cli --bigkeys` 扫描）；是否有慢查询（`slowlog get`）。

130. **【OPS-010】Java 应用频繁 Full GC**
     - **现象**：应用卡顿，通过监控发现 Full GC 频繁。
     - **排查**：使用 `jstat -gcutil <PID> 1000` 观察；使用 `jmap -dump:format=b,file=heap.hprof <PID>` 导出堆快照，使用 MAT 工具分析内存泄漏对象；检查是否有大量大对象未释放。

131. **【OPS-011】服务器 SSH 连接不上**
     - **现象**：终端连不上。
     - **排查**：能否 ping 通服务器；使用 `telnet <IP> 22` 测试端口是否开放；检查服务器防火墙 (`iptables -L` / `firewall-cmd --list-all`)；检查 SSH 服务 (`systemctl status sshd`) 是否宕机；是否因多次密码错误被 Fail2ban 封禁。

132. **【OPS-012】应用日志报 "Connection refused"**
     - **现象**：应用无法连接外部服务。
     - **排查**：目标服务没启动或者端口没监听；检查 `netstat -lntp` 或 `ss -lntp`；检查目标 IP 和端口是否正确；检查防火墙是否拦截。

133. **【OPS-013】应用日志报 "No route to host"**
     - **现象**：网络不可达。
     - **排查**：目标 IP 不在同一网段，且服务器没有配置默认路由或路由不可达；检查 `ip route`；检查目标机器是否宕机。

134. **【OPS-014】Docker 容器启动后立刻退出**
     - **现象**：`docker ps` 看不到容器。
     - **排查**：使用 `docker logs <容器ID>` 查看启动报错；检查主进程是否在前台运行（PID 1）；检查 Dockerfile 中的 `CMD` 或 `ENTRYPOINT` 是否写错；检查端口是否被占用。

135. **【OPS-015】Docker 容器内无法访问外网**
     - **现象**：容器 ping 不通外网。
     - **排查**：检查 Docker 宿主机是否能上网；检查 Docker 的 `daemon.json` 和网桥配置；检查是否在容器启动时使用了 `--network none`；检查 iptables 的 NAT 转发规则是否被改动。

136. **【OPS-016】Kubernetes Pod 一直处于 CrashLoopBackOff 状态**
     - **现象**：Pod 反复重启。
     - **排查**：`kubectl logs <pod-name> --previous` 查看上一次崩溃的日志；`kubectl describe pod <pod-name>` 查看事件；检查 Liveness Probe 配置是否过于激进；检查内存限制 (limits) 是否过小导致 OOM。

137. **【OPS-017】服务器被植入挖矿病毒**
     - **现象**：CPU 跑满，出现陌生进程。
     - **排查**：`top` 发现名为 `kdevtmpfsi` 或随机字符串的进程占满 CPU；检查 `crontab -l` 是否有恶意定时任务；检查 `~/.ssh/authorized_keys` 是否被添加了陌生公钥；使用 `chattr +i` 锁定文件，清理病毒，修改所有密码。

138. **【OPS-018】SSL 证书过期**
     - **现象**：浏览器访问提示“连接不安全”或“证书已过期”。
     - **排查**：使用 `openssl s_client -connect 域名:443` 查看证书有效期；更新证书文件并重载 Nginx (`nginx -s reload`)。

139. **【OPS-019】Nginx 报 "Too many open files"**
     - **现象**：无法处理新连接。
     - **排查**：Linux 文件句柄限制不够。在 `limits.conf` 和 `nginx.conf` 中增大 `worker_rlimit_nofile` 和 `nofile`；或配置 `worker_connections` 增大连接数。

140. **【OPS-020】服务器时间不同步导致服务异常**
     - **现象**：集群节点时间不一致。
     - **排查**：检查 `chronyd` 或 `ntpd` 服务是否运行；配置 NTP 客户端同步内部 NTP 服务器或公网源 (`ntp.aliyun.com`)；手动同步 (`ntpdate`)。

## 八、 Linux 运维工程师故障排查

141. **【LNX-001】使用 `df -h` 查看到磁盘有空间，但无法写入文件**
     - **现象**：提示 `No space left on device`，但 `df` 没满。
     - **排查**：极大概率是 inode 用完了。使用 `df -i` 查看 Inodes 使用率。清理小文件（如 `/var/spool/postfix` 中的邮件队列、日志产生的临时文件）。

142. **【LNX-002】删除了大文件（如日志），但 `df` 显示空间未释放**
     - **现象**：磁盘空间依然被占用。
     - **排查**：有进程仍然打开着该文件句柄。使用 `lsof | grep deleted` 找到对应进程 PID，重启该进程或使用 `> /proc/<PID>/fd/<fd号>` 清空（不推荐，最好重启）。

143. **【LNX-003】使用 `kill -9` 无法杀死进程**
     - **现象**：进程顽固存活。
     - **排查**：进程可能处于 `D` 状态（不可中断睡眠），通常是在等待 I/O（如硬盘坏道、NFS 挂载超时），无法接收信号；也可能是僵尸进程 (`Z` 状态)，需要杀死其父进程。

144. **【LNX-004】系统日志 `/var/log/messages` 被写满**
     - **现象**：根分区被日志占满。
     - **排查**：检查 `rsyslog` 或 `syslog-ng` 的配置；配置 logrotate 进行日志轮转；排查是否有程序在疯狂报错（如内核错误、硬件故障）。

145. **【LNX-005】修改了 `/etc/fstab` 后，重启服务器进入 emergency mode**
     - **现象**：系统无法正常启动。
     - **排查**：`fstab` 写错或挂载的磁盘/网络存储不可达。输入 root 密码进入救援模式，重新编辑 `fstab`，注释掉错误的挂载项，重启。

146. **【LNX-006】无法通过 SSH 密钥登录，总是提示输入密码**
     - **现象**：免密登录失效。
     - **排查**：检查 `~/.ssh/authorized_keys` 文件权限，必须是 600；`~/.ssh` 目录权限必须是 700；检查 `/etc/ssh/sshd_config` 中 `PubkeyAuthentication` 是否开启。

147. **【LNX-007】`sudo` 命令提示 "user is not in the sudoers file"**
     - **现象**：普通用户无法提权。
     - **排查**：切换到 root，使用 `visudo` 编辑，在 `root ALL=(ALL) ALL` 下面添加 `用户名 ALL=(ALL) ALL`。

148. **【LNX-008】端口被占用，服务无法启动**
     - **现象**：`Address already in use`。
     - **排查**：使用 `ss -lntp | grep <端口号>` 或 `netstat -lntp` 找到占用该端口的进程 PID，`kill` 掉该进程，或修改新服务的端口。

149. **【LNX-009】Cron 定时任务没有执行**
     - **现象**：到了时间脚本没跑。
     - **排查**：检查 `crond` 服务是否运行；检查脚本是否有执行权限；检查脚本内的命令是否使用了绝对路径（Cron 环境变量极少）；检查脚本内的输出日志，看是否报错；查看 `/var/log/cron`。

150. **【LNX-010】忘记 root 密码**
     - **现象**：无法登录系统。
     - **排查**：重启进入 GRUB 菜单，编辑内核启动参数，在 `linux` 行末尾添加 `rd.break` 或 `init=/bin/bash`；挂载根分区为读写模式 (`mount -o remount,rw /sysroot`)，执行 `passwd root` 修改密码；如果开启了 SELinux，需创建 `.autorelabel` 文件。

151. **【LNX-011】执行 `tar` 解压时报错 "Unexpected EOF"**
     - **现象**：解压失败。
     - **排查**：压缩包在传输过程中损坏（如通过 FTP 传输未用二进制模式）；磁盘空间不足导致写入中断；重新下载或重新打包上传。

152. **【LNX-012】`find` 命令查找文件极慢**
     - **现象**：卡住或耗时极长。
     - **排查**：在大目录下查找时，限制搜索深度（`-maxdepth`）；排除不需要搜索的目录（如 `-path ./proc -prune`）；如果是查找文件内容，优先用 `grep -r` 或 `rg`（ripgrep）。

153. **【LNX-013】用户登录后立刻被踢出 (Shell 损坏)**
     - **现象**：输入账号密码后直接断开。
     - **排查**：用户的默认 Shell（如 `/bin/bash`）被误删或损坏。通过 root 登录，检查 `/etc/passwd` 中该用户的 Shell 路径，重新安装 bash 或修改为 `/bin/sh`。

154. **【LNX-014】使用 `yum` 或 `apt` 安装软件报错依赖冲突**
     - **现象**：无法安装。
     - **排查**：清理缓存 (`yum clean all` / `apt clean`)；更新源 (`yum update` / `apt update`)；使用 `--skip-broken` 尝试跳过冲突包；或者手动下载 RPM/DEB 包强制安装。

155. **【LNX-015】文件系统损坏，提示 "Structure needs cleaning"**
     - **现象**：无法访问目录。
     - **排查**：通常是因为非正常关机导致。卸载该分区，然后使用 `fsck -y /dev/sdX` 进行修复；若无法卸载，需进入单用户模式或 LiveCD 修复。

156. **【LNX-016】`ping` 外部域名提示 "Name or service not known"**
     - **现象**：DNS 解析失败。
     - **排查**：检查 `/etc/resolv.conf` 中的 DNS 配置（可添加 `nameserver 114.114.114.114`）；检查网卡配置中是否配置了 DNS；检查 `/etc/nsswitch.conf` 中 `hosts` 配置是否正确。

157. **【LNX-017】`rm -rf` 删除了文件，想要恢复**
     - **现象**：误删重要文件。
     - **排查**：如果文件还被进程占用，去 `/proc/<PID>/fd` 下找；如果未被占用，立刻卸载分区，使用 `extundelete` 或 `testdisk` 尝试恢复，切记不要往该分区写任何新数据。

158. **【LNX-018】不能切换到 root 用户，提示 "Authentication failure"**
     - **现象**：`su -` 失败。
     - **排查**：`/etc/pam.d/su` 中可能限制了只有 `wheel` 组才能切 root；或者 PAM 模块配置错误。检查 `/etc/security/access.conf` 限制。

159. **【LNX-019】系统启动卡在 "A start job is running for..."**
     - **现象**：开机卡住 90 秒或更久。
     - **排查**：某个 systemd 服务（如网络、磁盘挂载）超时。查看提示的服务名称；进入系统后使用 `systemctl disable` 禁用它；或检查 `/etc/fstab` 中挂载的网络存储是否断开。

160. **【LNX-020】`grep` 搜索包含中文的文件时显示乱码**
     - **现象**：中文变成了问号或乱码。
     - **排查**：检查文件的编码（`file -i filename`）；如果是 GBK 编码，需使用 `iconv` 转换为 UTF-8 后再 `grep`；或者设置终端的 `LANG=en_US.UTF-8`。
